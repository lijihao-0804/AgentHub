# Source-preserving merge and refill at six passages

This exploratory rule was specified before running the comparison. FiQA TEST and the 553-query SciFact TRAIN cohort were examined in earlier project studies, including the sixth-slot retention experiment. Neither data set is a fresh holdout.

For each original archived BGE ranking, A takes ranks 1–6. For B, examine pairs in lexicographic order of their original rank positions `(i, j)` with `1 <= i < j <= 6`. Choose the first pair with the same source, a known identical revision, and overlapping or directly touching displayed character intervals. Both original slices must exactly match the pinned indexed full text. Their union must be a single continuous source slice and contain no character outside the two component intervals. A one-character gap disqualifies a pair. Retain both component chunk IDs, original locators and displayed intervals in the research citation. Labels do not select the pair.

For refill, choose the first chunk in original ranks 7–20 from a source absent from all of A’s six. Put the merged interval at position i, drop position j, preserve the remaining relative order, and append the refill. If no verified pair or new source exists, keep A. Try one pair and one refill per query, shared across budgets. Never rerank, tune alternatives or replace an existing citation in product storage.

Independently at 512 and 16,000 project estimated evidence tokens, pack A and the proposal with the production whole-record selection and serialize the evidence user message. Assert that 16,000 displays all six. For each displayed A window, its entire original interval must be covered by the union of the proposal’s displayed intervals with the same source and known revision. Permit an unchanged, identical indexed chunk to retain itself even when its revision is unavailable. A missing character, source or revision means the proposal falls back to the original A message for that budget. Accept a retaining proposal even when packing omits the refill. Report opportunities, accepted proposals, fallbacks, genuinely changed messages and visible refills separately. Never emit more than six records.

Use the same fixed inputs and outcome definitions as `sixth_source_retention`. Report document qrels as hit queries, matched positive pairs and per-query macro recall. FiQA has 648 queries. It supplies no sentence-level rationale. Checking coverage of the entire nonempty published answer text is a distinct proxy. SciFact has 553 queries and 379 annotated query–source pairs. Report complete official evidence sets, source pairs with any complete set, and annotated questions with any complete set. Compute paired gains and losses even when aggregate coverage is unchanged. Record a digest of all actually displayed source spans and citations, and examples with the component provenance. These measurements concern an offline message projection. The API currently represents one stored chunk per citation and does not define a persisted composite citation.
