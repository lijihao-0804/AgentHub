# Refusal consistency evaluation

Baseline source is 46362e9245c7a708d015f1bd2a462d850cb0e118. Both arms use that experiment's evidence-sentence reranker, the same twenty candidates, at most six reader passages, the same reader model, prompt and budget. The only intended change is the handling of contradictions between a decoded answer and its insufficiency flag. Citation validation still applies.

Before dispatch, freeze the independent IDs, source exclusion ledger, gold, code and order. Use 50 previously unused questions from different QASPER train papers (30 answerable, 20 officially unanswerable), once per arm through the authenticated public HTTP route. Count the first user request including errors. Count internal provider attempts separately. Six additional control requests cover the Vietnamese platform, 1,001 tasks and the prior correct Python answer, once per arm. Historical controls and concurrent calls use separate sessions and never enter the 100-request denominator.

Grade shuffled responses against gold and actual cited original passages. Report first-answer correctness over all 50, correctness among 30 answerables, correct refusal among 20 negatives, and citation support with named denominators (all claims supported per substantive response, and supported individual citations). An official negative with a defensible answer remains a failure against the official label and is also identified separately. Report HTTP errors, false refusals, individual paired gains/losses, evidence equality, and baseline-correct retention. Absence of a citation in a refusal earns no citation credit.

Run archived previously correct responses through the new service with the same captured answers and references, distinguish reconstructed terminal outputs from original provider logs, and check the three real controls. Where terminal responses are available in the new run, apply both readers to identical output to distinguish a rule-induced change from different generations. Keep per-case data alongside aggregate percentages.

Promote the combined change only if independent first-answer correctness or correct refusal improves, first-answer correctness, correct refusal and citation support do not decline, the new arm retains paired previously correct answers, the historical replay preserves previously correct responses, and the Vietnam and 1,001 controls pass with the right flag and supporting sources where applicable. Report actual exceptions and leave the candidate experimental if that comparison fails. This is a paired development evaluation on public train data, not a formal holdout experiment or a population-level guarantee.
