## 新题的实际结果

50 道全新 QASPER TRAIN 题来自 50 篇不同论文，包含 30 道可答题和 20 道官方无答案题。每题从已认证的 `POST /api/v1/knowledge/query` 各发一次旧读者 A 和新读者 B。两臂都使用上一轮的证据句重排。每一对拥有相同的前 20 个候选、送入模型的六段有序原文和初始系统及用户消息。在正、负例内各有半数先发 A，半数先发 B。两个 502 均保留在分母中。历史控制另计。[抽样和排除范围](cohort.md) · [实际证据、首次物理请求及同输出复核](receipt-audit.json)

## 变动来自哪里

对本轮 98 份成功的独立答复，把同一份模型终态 JSON 分别交给两套本地逻辑，发生改写的次数为 **0/98**。六次历史控制也没有改写。DOVER 的两次云端生成分别给出 true 和 false，冻结规则没有识别“平均数未给、只有方向”的表达。两个 502 都发生在候选组的可答题：一题问论证影响力的语言特征基线，一题问翻译系统。两次阿里云都返回 HTTP 200，模型各用完 2,048 个输出 token，终止原因为 `length`，没有可见答文。网关在引用校验和新规则之前返回 502。此次独立组 100 次首次 HTTP 对应 104 个供应商 POST，历史组 6 次对应 6 个；四次额外调用是接口原有的引文纠正。[物理调用与失败详情](provider-calls.json) · [两组公开终态对照](receipt-audit.json)

检索两臂相同。在 30 道可答题中，完整金标准段落在前 20 命中 15/30，在读者六段中命中 12/30。能在候选中找到整段时，保留率为 12/15（80%）。金标准答案字符串在两个阶段分别命中 23/30（76.67%）及 20/30（66.67%）。这些是逐字命中指标；换一种说法仍可能提供充分证据。[召回分项](receipt-audit.json)

## 历史三题

- **越南平台**。旧接口要求引文编号可见、正文标记与编号集合匹配，满足后直接采用模型的布尔标志。[3] 和 [5] 只支持数据来自 VLSP 共享任务及评论或帖子，无法识别具体平台。本轮两组新生成均主动拒答，返回 true、空引文。与上轮相比，越南题的前 20 排序有变化，送入模型的六段原文与顺序一致。[八个旧负例的逐题归因](history.md)
- **1,001**。两组都在首答给出 1,001，引用可见证据 [3]。原文为对照组 496、AUI 组 505，合计 1,001。引用指向论文 `1707.06939` 的第 7 块（从 0 编号），与上轮一致。[修复后历史首答及原文](live/B-historical.json)
- **Python**。两组都首答 Python，并引用 [1] 的目标语料说明和 [3] 的框架语言说明。三道控制的六段正文与上轮证据句重排逐项一致。[历史对照](provider-calls.json)

上轮 8 道“官方应拒答却作答”中，越南平台和人类直觉采集题都承认关键事实缺失，但附了背景引文。本轮规则纠正了前者，后者的模拟细节仍被保留。另两题答错了数量口径或统计对象，其余四题有可定位原文支持实质回答。规则仅在原始结构与引用校验通过后处理可确认的整体拒答，默认关闭。数据来自开发用 TRAIN 子集，本轮没有暴露正式 holdout。[同输出诊断](historical-diagnosis.json) · [离线复验与真实入口复跑](replay.md)
