# 独立样本与评分

两臂共用 50 篇论文。论文正文由标题、摘要、章节标题和正文段落组成；每篇只选一道题。所有问题、答案和证据都来自 QASPER v0.3 官方 TRAIN。参考答案和标注段落只用于评审。可以用协议里的逐篇 SHA-256 核对两个检索库上传的文本。[冻结协议](protocol.json)

抽样前用本地历史记录比对官方题号、论文号、论文标题、问题原文和 JSON 转义后的形式。命中一道题会排除其整篇论文，同一问法会连带排除其他论文中的同题。上轮 48 篇独立论文、16 篇历史语料以及早期明确预留的 19 篇、54 题都在排除集合内。最终排除 393 篇、754 题，包括问法标准化后发现的 4 个重复题号。新样本与历史题号和论文号的交集均为零。台账记录了各类匹配的本地首个出处和范围，外部或已删除记录、已有全量数据字典和一个旧临时目录在扫描边界之外。[排除台账](exposure.json)

按固定盐值和官方题号的 SHA-256 排序，选入 30 道有单一抽取答案、单个完整证据段的可答题和 20 道官方无答案题。每篇正文最多 30,000 个字符，选中的原始问题经过大小写和空白标准化后仍互不相同。按第二个固定盐值安排题序，在正、负例内分别平衡两个方法先答的次数。每一臂在 15 道正例、10 道负例上先发。历史上的越南社交平台、1,001 个任务响应和 Python 语言三题使用各自原有语料库，另计六次请求。[方法与先后顺序](protocol.json)

评分把每次首答的实际问题、答文、编号引文和官方标注组成匿名项，完全相同的内容只判一次。每位评审独立判断答案类别、逐条引文支持和整答事实支持，再对有实质分歧的匿名项裁决。50 题整体正确率只计完整有据正答和结构化正确拒答。报告另列有证据能够回答的官方负例、可答题被拒、HTTP 错误和同一供应商终端输出在两种处理下的诊断结果。[评分规则](rubric.md) · [上线判据](acceptance.md)

在查看试验答文前，另行检索了 20 道官方无答案题所属论文，至少 7 篇直接给出了所问内容。例如，关于引文生成语料的问题，原文说明如何从 15.4 万篇 S2-GORC 文章抽取 62.2 万个引用句；土耳其语语音识别论文也明确指出使用 IARPA Babel 的会话录音。17 个可核验段落保留原文位置与哈希。后续引文评分仍只依据该份答复实际引用的内容，其余 13 题在这项核查中未记为明确冲突。[官方标注与论文原文核对](official-negative-source-audit.json)

从仓库根目录可复验语料、历史排除、标注、分层先后与评分。

```powershell
.venv/Scripts/python -m benchmarks.public_rag.refusal_consistency_review --check
```
