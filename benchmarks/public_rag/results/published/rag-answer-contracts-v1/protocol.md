# 回答合同与业务事实一致性 · 配对确认协议 v1

## 样本与干预

两组分别使用 PR #19 的 `de45ac6` 行为和 `freeze.json` 绑定的候选实现。整块 BGE 为默认，两组均关闭 C/D。CitationQA 使用相同的有序可见段落和用户消息，沿用 PROMPT_JSON、最多 6 段、6000 近似 token、单次生成。每题的独立合成快照按正文 1200 字符、重叠 160 切块，两路各取 30、RRF 候选 20，再整块 BGE 重排。原文可答但当前快照未收录答案的题独立记录额外原文，额外原文仅用于评分。客服每题每臂建独立数据库、客户、索引、快照与线程，使用相同政策内容、初始业务事实、订单工具、批准决定和业务时间。记录真实绑定的 ID 和内容哈希，分别校验所见证据及附加说明占用。

每条链路 16 个新输入、32 次首次任务机会。CitationQA 为 6 个证据完整、6 个不足和 4 个部分可答/多子问。客服为观察范围与空值、字段含义、政策引文、能力与执行四层各 4 个。样本按清单顺序跨链路交错，组内采用 AB/BA 交替，完整次序在 `freeze.json`。分层、可答性、是否需保留判断、核心事实、必需 READ 与允许的 WRITE 在首答前锁定。采用内部编制的合成数据，没有官方标签或外部盲测主张。旧 40+52 题只作开发回归。

## 计量、资源与停止

使用北京百炼 `deepseek-v4.1-flash-1017`，OpenAI-compatible 单部署，温度 0，单次输出最多 2048 token，每个请求最多预留 32,768 输入 token。CitationQA 关闭思考；工具调用沿用 PR #19 的已发布 provider-default 模式，两臂一致。无后备、纠错模型、自动重试或付费评审。客服每题每臂最多四次物理 POST，包括工具与审批恢复后的调用。单机串行，一次只允许一个出站请求及一个活动任务。新账本创建需要本轮授权。

预算以北京忙时每百万输入 2 元、输出 8 元计算。估算参照旧 B 的 40 题与旧客服的 52 题真实平均用量，按本轮两条链路各 32 个首答机会换算，约 **1.44 元**。新场景、附加输入及工具轮数会改变实际费用。最终分别记录供应商确认用量、估算费用、未知派发保留金额和可取得的实扣账目。[北京计费](https://help.aliyun.com/zh/model-studio/model-pricing)

先持久化首次任务和每笔物理派发，再调用。任何一笔用量、费用或派发不明都保留预留并停止。代码/数据/评分漂移、证据记录缺失、上限不足、Agent Run 非终态或未知写入也暂停。发生身份失效时按原任务 ID、线程/Run 与收据只读核对，结果已知且收据完整后才继续首次派发尚未执行的尾部；旧请求、turn、审批或工具写入都不重交。禁止以同一授权重建正式账本或另开输出目录尝试相同样本。

## 判分与报告

按清单中的问题事实、可答性及必要工具逐条评判。所有已派发机会计入主分母。已派发后合同失败、无终答、运行失败、未知状态均计 0。未派发单列。正确可答任务需要保留所有要点与条件，逐主张有可见证据且引用正确。严格拒答无引用可以通过。部分可答需同时给出可回答部分及其出处，并明确标出不可判断部分。以原文任务和清单要求为主要口径，另报可见证据下是否合理保留。原文完整可答但可见证据缺失时，保守拒答可以是合理行为，原文任务仍计失败。事实、能力、执行和政策附加断言一并评，不以 Run 成功代替首答正确。

客服必需 READ 看成功工具步骤。允许 WRITE 须符合预定审批、执行、客户/主题、持久化工单与准确回执；审批拒绝或禁止写入须保留原业务状态。合成工具中的未知值、时点和查询范围按该案例判据解释。分别计算缺据或冲突处理、误拒、事实/能力/政策错误、无终答、所引 ID 的定位与语义支持、首答成本与 p50/p95 时延，公开指标附分子、分母。两个数据库的原生块 ID 可不同，比较来源与最终段落文本 SHA-256；检索查询变化、轮数变化或预算挤掉段落时按题披露。输入成本计数记录每轮附加系统说明、观察字段和实际输入；本地 tokenizer 的拆分估计与供应商总量分别报告。

证据包匿名编号并打乱，保留模型失败时的可见原始输出。未涉及实现的评审者按冻结判据审阅每道题每个引用，并写简要依据；付费评审次数为 0。使用 Codex 评审时明确模型身份，另行复核分歧，保留初评和最终裁决。原始工具文字可能暴露组别，应披露盲态限制。程序核对评审字段、定位 ID、终态与业务写入。每条链路各报配对胜/负/平、正确率差、按输入配对重采样 10,000 次的 95% 百分位区间（种子 20261114）。缺一臂的输入不参与配对区间，同时保留已派发一臂的失败与分母；未完成全计划不能宣布验收通过。区间跨零时仅陈述样本趋势。出现新严重事实、引用或执行错误时保留候选为实验配置。两链路独立决定。
