# CitationQA 固定输出重放

运行仓库根目录的命令 `.venv/Scripts/python.exe -m benchmarks.public_rag.replay_answer_contracts`。只读 PR19 的原始输出和既有裁决，按历史 manifest 校验输入文件，再执行产品的单响应解析入口。无需联网、模型或检索。逐条正文口径见 [replay-body-review.json](replay-body-review.json)，旧新终态与原文见 [replay-results.json](replay-results.json)，分母与计数见 [replay-summary.json](replay-summary.json)。

## 状态判据

| 正文及证据 | 候选字段或终态 |
| --- | --- |
| 充分支持的完整回答、有依据的否定 | false，正反结论均保留对应引文。 |
| 部分可答、部分未知；主体回答附带限制 | false，给出有据部分、必要条件与出处，说明具体缺口。 |
| 整体拒答 | true，正文只说明无法回答的范围，零出处。 |
| 已知为通篇拒答，且旁证只定位未提供的章节 | 严格检查原始编号、对齐单一问题所缺属性；可删除纯定位句、保留原拒答句，记录转换和哈希。 |
| 拒答理由含应保留的来源事实 | 已声明 true 且带引用时失败。false 但明确否认可完成请求的比较、余文仅述单方事实时，保留原文记录并失败。未识别的表述仍可能返回。 |
| true 但正文以明确肯定作答开头 | 冲突失败。完整语义一致性仍依赖生成和内容审查。 |
| 契约矛盾可无损恢复 | 纯拒答可以去冗余的合法编号，并同步正文、布尔与数组；false 的两路引用不匹配保持失败。 |
| JSON、字段类型、重复键、原始引用非法 | 严格解析或白名单失败。实际可见编号可以稀疏，候选保留规范的正十进制标记。规范化后重新执行字段与正文完整合同。 |

`AGENTHUB_KNOWLEDGE_QA_ANSWER_CONTRACT_V1=true` 启用候选生成提示和单次派发，默认沿用 PR19。纯处理和两种输出模式共用 `resolve_citation_answer`、`citation_system_prompt`。生成和修复分开计证。原始模型正文只在内部回执和已授权的开发重放中使用，成功转换的追踪携带规则及内容摘要。公开 API 返回字段不变。普通否定、数字界限、多子问与带事实条件的回答均有对照。规则不读取题号、金标、检索文本或评分结果。范围和推理正确性无法从引用编号合法性推出。

## 逐条复核与分母

- PR19 冻结判据按三个臂各 40 次机会计。119 次有实际原始模型内容，另一次 C 选择失败无正文，后者没有哈希，纳入 120 次机会。原文主指标排除预先判歧义的 3 题 × 3 臂，保留全部失败终态作为错误。旧实现逐条与历史状态、成功返回的三个字段和原文得分核对。
- 58 条历史语义拒答在旧默认和旧 contextual 模式均命中 0 条。该组同时包含部分答案。复核以“是否回答了任何一个所问部分”为准：例如专家参与程序、具名评估指标、共享程度固定的性质、不同实验中的定性比较都有应保留的归属。相反，仅列相关工作并明确表示无法指认实验比较对象，仍属整体拒答。原历史分组和原文任务分数原样保留；正文复核为本轮内部开发审阅，未做独立盲审。
- 完整输出合同合法 93/120 → 91/120（按实际生成 93/119 → 91/119）。此前有终答的 3 条“无法比较”包含被引用的模型结构事实，新状态冲突会失败。另恢复 1 条只引用结果所在章节的整体拒答；原文可答，实际六段未送达所需指标，故只有输出合同恢复。此前正确首答被错误改成拒答为 0。
- 状态与正文一致且合同有效 68/120 → 69/120。仅在有效输出中为 68/93 → 69/91。119 条原始字段与正文一致 93 条，其中含最终因引文合同失败的输出；这衡量模型原文，不代表服务返回。原始正文整体拒答 51 条，依据 PR19 可见证据判断，43 条合理、8 条应答而拒。有效返回的结构化拒答 1 → 2，分别 1 和 2 条合理，错误均为 0。仍有未识别的整体拒答，不能以结构化错误拒答为零代替全文判断。
- 原文完整任务正确 55/111 → 55/111。对于未改文本采用冻结内容判决；新增终态失败记零；恢复的拒答只在原文判不可答时可能计分。9 个歧义机会单列。逐条 `meaning_preserved`、`lost_necessary_information` 在无输出时为 null，明确区别服务未交付与对实际文本的删改。新触发的拒绝交付计入 `new_failures`。这些数字来自固定输出；生成约束的有效性、新题首答和时延仍待真实配对。
