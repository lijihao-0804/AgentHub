# 2,048 token 解决了本组截断，但单改额度未达到答案保留标准

14 道独立题按题交错发送，两边各先答 7 题。候选前 20、重排结果、
读者前 6、实际传入适配器的用户与证据消息逐对相同。两臂各只发了
14 次模型调用，输入均为 31,724 token。输出分别为 4,173 和 4,555
token，中位 HTTP 耗时 31.22 和 31.16 秒；按最近秩计算的 p95 为
38.53 和 62.36 秒，小样本的 p95 即各臂最大值。未取得实际账单。

|独立题|512（旧建档）|2,048（配置额度）|
|---|---:|---:|
|首次 HTTP 200|11/14|14/14|
|可答题完整且有据|8/10|8/10|
|保留原完整正答|—|7/8|
|官方无答案题正确拒答|1/4|2/4|
|引文支持至少一个所附事实|17/17|31/31|
|标注论文进入候选 / 读者|10/10、10/10|10/10、10/10|
|完整官方证据段进入候选 / 读者|7/10、7/10|7/10、7/10|

三个错误全部有供应商实际返回的长度终止标志。其一为零可见正文，
被网关拒绝；其二、三为可见输出未通过严格 JSON 解析。这三题在
2,048 下全都正常结束，但只有一句“HTTP 200”并不能说明答案正确：
一个原来答对的意大利语词向量问题，候选报对了数值，又说来源为
意大利 Wikipedia；被引用的原块从日期中间开始，证实不了这项附加
断言。两名独立盲评者均判为未获引文充分支持。另一道声学语言模型
的题，两臂都描述了目标语言的配对文本，均未给出官方标注的 BABEL
名称；严格口径两臂均记部分正确，若采用另一位评审的读法两臂均
多一题完整，不改变未通过的保留门槛。

另外两道历史诊断也实测复现了 502：512 的 620 返回空可见正文、
`length`，VG 有正文但在上限时 JSON 解析失败。2,048 均返回 200，
但只有 VG 的数据量与引文直接相符；620 没有区分间质耗竭与题干
要求证明的纤维化减少，仍不能计为有据正答。这证明了同样的两种
故障机制能在真实入口出现，不能反推旧的九次请求都因截断而失败。
