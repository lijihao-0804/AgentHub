195 份历史回执含两个无可见正文的 length 终止，均保留 MODEL_BAD_RESPONSE。其余 193 份成功答复中，早期 95 份只能重建公开终态字段，不能重建供应商 JSON 字节或 citation_ids 原排序。早期另有一份无原始正文的 JSON 解析失败，未计入回放。后期 98 份保留了终态模型字段及供应商正文 SHA-256。回放针对终态，仅在真实服务中保留原有最多一次的引文纠正。两臂回答同一题只算一道题。此次新增供应商请求 0，新增费用 0。

**默认决定。** `POST /api/v1/knowledge/query` 在引用合法时，将全文恰好声明“证据不足、无法回答”的中英文限定表达统一为 true、空引文。默认规则只命中一个构造的矛盾输出，本次历史样本尚未观察到默认规则带来的真实修复收益。对同一份模型输出做此规范化无需再次生成。

**可选决定。** `AGENTHUB_KNOWLEDGE_QA_CONTEXTUAL_ABSTENTION=true` 增加单一实体或平均降幅的保守模式。越南回执保留了平台名未给出的声明，删除 VLSP 背景和引用 [3][5]。DOVER 另一次真实终态只给出定性改善，明确两次承认缺少平均数。可选模式保留首句、删除定性比较及 [1][4][3]。两条都改变了实际交付状态，且确实省略了已引用的背景信息。它们是从已看过的问题开发出来的狭窄修复，无法据此估计泛化收益。其他 193 份历史回执结果相同。旧实验的 1 得 1 失来自独立生成，不进入本轮同输出计数。

**保留的边界。** 人类直觉题正文承认缺少从人类收集的过程，并给出有引文的模拟方法。本轮保留原文、标志和引用，把是否响应问题留作独立评测。多子问题、定量下界、局部否定均不按整段拒答处理。有据答案被标 true 且仍有引用时，继续触发 citations_on_refusal，在 PROMPT_JSON 模式下可经原纠正请求改正。true 且无标记的实质回答仍有歧义，自动提升为正式作答会缺少可定位引文。JSON 错误、引用越界、不可见输出和 length 标识分别沿用原分类。通用工具型 Agent 的自由文本没有此布尔字段，客服验收应独立检查适用条件、引用及持久回执。
