C 的 23 个成功请求在原始消息完全一致后，由现有 EvidenceSetSelector 验证历史响应并选择条目。其余一题保留原 HTTP 400 与历史整块回退。历史 23 份已知用量合计 73,572 token，400 用量未知。D 在同一批原始段落上用本地 BGE 重新计算句对分数，复用整个块的历史打分。窗口来自原文，最高分窗口抬高整个块。D 减少一题完整支持，不能据此提升为默认。两个控制组没有新增模型生成，新增供应商物理请求为零。A/B 的等价范围限于这些固定输入的排序和交付。源代码差异包括计时起点与 RRF 调用封装。

句窗对显式英语引述标题只在窗口打分时去前缀，召回和整块打分保留整问。标题仍影响召回，窗口步骤不会把来源限制为指定论文。旧 QASPER 的四种消融显示只去标题和只加窗口都没有产生组合的净增；最大句对可能偏好背景句。在最新的五个拒答失败里，模因标注题的六段甚至没有一段来自目标论文。历史已曝光的 48 道 QASPER 初答中，组合为 37/48、整块 34/48，4 得 1 失；GPU 重排中位 0.27→0.95 秒。不能据此预测新确认集回答效果。本轮只移植原组合，没有二次调参或新增模型补检。

五个错误拒答的完整原文核查见 five-refusals.json。对每个前 20 候选使用冻结 QASPER TRAIN 原文和修订 ID 重新计算 chunk 身份，对六段实际读者文本与首次物理消息哈希进行核对。FastText 的四段目标论文候选没有给出算法名；ESIM 的 chunk 3 写了第一次 LSTM 编码及第二次读取，但六段中只有未完整交代第一阶段的 chunk 14。其余三个问题的语料语言、DDI 规模和模因标签依据均进入候选又落选。原题的字面统计为 2 个未入池和 3 个未保留，按原文等价关系修正为 1 和 4。期望证据与复核短语仅供评分。历史五题走独立 Citation QA，本次 Agent 的各阶段以独立产品回放记录，不把两者拼成同一次 Run。未发现可在运行时仅凭用户问题和可见上下文可靠判别 FastText 缺口的触发条件，本轮不增加补检调用。

产品修复使两个快照共享同一个 chunk 时只留其首个配对来源，让被挤占的下一条证据恢复；不同页面、段落的块内坐标分别去重。原始搜索结果在 2,000 字后的例外条件不再被静默截掉，整条记录交给预算准入。定向测试验证不足时跳过整条、继续回填以及可见来源配对。已发布版本的 retrieval_config 可显式设 rerank_method 为 sentence_evidence_v1；不选该值使用整块。附加句窗阶段出现模型错误或无效数值会沿用已验证的整块结果，并记录 rerank_fallback。基线计算失败仍作为检索错误处理。

### 发布互补选择器

在 Agent 的 retrieval_config 指定 evidence_set_selector 为 complementary_v1，使用固定版本已有的原始记录投影和有界 context_budget_bytes（最多 20 个候选、10 条证据）。每个 PINNED 快照单独选择；同次搜索绑定几个有效快照，最多就可能增加几个选择请求。沿用发布模型的主模型、提供方、工作区凭据和受限出口，仅一次、无备选链，输出至多 256 token。模型读入全部候选须先获 ContextBudgetPolicy 准入。运行成本硬限额没有可用于该步骤的事前报价时不派发。保留时间不足、不允许计费、附加选择输出无效、已知提供方失败等情况沿用当次已授权候选的整块排名。取消向上传播，实际超时维持未知使用量，无自动重试；快照/权限/凭据完整性失败不触发降级。Run 的 EVIDENCE_SELECTION 步骤标明每个快照 selected/fallback、原因及条数。AUXILIARY_MODEL 与检查点 usage_records 记录辅助调用及供应商返回的用量，未提供的用量或费用保持未知。没有将测试用的假网关调用计为云端验证。
