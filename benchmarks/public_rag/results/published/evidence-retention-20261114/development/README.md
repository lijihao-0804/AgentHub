## 1,001 条回答的原始证据

论文 `1707.06939` 的第 7 号块（编号从零开始）覆盖原文字符区间 `[7000, 8200)`，是前 20 中唯一完整包含标注段的块。融合阶段把它排在第 15。历史设备的 CPU FP32 整块 BGE 给它 −1.63053，第 10 位。原第 6 位的分数为 −0.43335。原第 1 位来自第 8 号块，得分 +0.59379，含另一次质量评价任务的 119 名评分者与 4,300 次评分。第 9、10 号块讨论工人的响应延时，原重排在第 2、3 位。这些是实测的竞争块和打分。

目标块在 CUDA FP16 的整块分数为 −1.62891。在题干去除带引号的论文名之后，原文 `[7483, 7642)` 的连续两句成为该块得分最高的窗口，−1.15723。第一句给出任务总数和分组数量，第二句说明这些回复何时收集。去掉第二句的前一个窗口 `[7393, 7563)` 同样含目标数值，只有 −6.22266。把最佳两句与原整块分数等权平均，得 −1.39307，候选第 3 位；保留给读者的是整块全文。单独改成去题名整块时该块第 4；保留完整问题、只做双句评分再与原块等权时第 6。标题对问题的竞争和跨句表达与这些观测相符，分数不能揭示模型内部的因果机制。

## 已冻结的打分

在同一批原候选上，用同一个 BGE 给完整问题与原始整块打分。另对每个自然段内相邻两句计算 BGE 分数；仅有一句的段落整体参与。若问题以带引号的论文、文章或文档名明确限定来源，句级分支去除该限定，整块分支保留原问题。每块取最高句窗分，与整块分各占一半，再按现有排序规则保留六个原始块。不调整文本、偏移量、模型权重或读者提示。模型 revision 为 `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`，实现的 LF SHA‑256 为 `079962e1fe172a3e66b524ddf0a24c247cee07d4609521b95e45f75883494901`。句级分数与原分结合的做法参考 Yilmaz 等人的文档检索研究。这里的地址偏移和原始块身份由 AgentHub 保留。[原论文](https://aclanthology.org/D19-1352/) · [BGE 作者模型说明](https://huggingface.co/BAAI/bge-reranker-v2-m3)

CPU FP32 与 GPU FP16 的原整块重排分别在 16/16 题上逐位复现了原回执中的六块。新旧前六每题平均重合 4.25 块。每题增加 133–188 个去重句窗的本地 BGE 配对。开发集上，只去题名后做整块打分也达到完整段 6/10、答案串 8/10，只用最佳双句分亦然。固定原前五、只用融合分增补第六个位置时，分别为 5/10 与 7/10，1,001 所在块仍未入选。因此这 16 道已曝光题用于确定候选并解释它的行为，不能独立估计句级分支的增益。
