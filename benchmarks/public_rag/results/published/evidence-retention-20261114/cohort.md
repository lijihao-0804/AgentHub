# 独立题与历史对照

从官方 QASPER v0.3 TRAIN 的 888 篇论文、2,593 道题中取样。本地历史扫描排除了 340 篇论文和 698 个题号，其中包括旧方案明确预留的全部 19 篇论文和 54 道题。扫描比对论文号、题号、题文和标题，也读取旧实验保留的压缩包内文本。题号和相同题文均关联到论文，任一命中就排除整篇。被排除的数量反映历史文本中出现过的标识或表述，实际执行过问答的数量另计。各类标识的首个来源可在台账中核对。[曝光台账](exposure.json)

按固定盐值计算官方题号的 SHA-256 并排序，每篇最多选一题。独立组含 30 道单一抽取答案、单一完整段落标注的可答题和 18 道官方无答案题。题目选自 48 篇不同论文，48 个官方题号、48 个带论文标题的 HTTP 问题均不重复，与历史扫描集合的论文和题号交集均为空。论文 1911.12569 和 1908.10322 各有一道提问模型参数量的无答案题，去掉各自论文标题后的英文问法相同。两题按冻结方案保留。两臂在每道题共用同一知识快照，独立组的首发顺序各占 24 题。[冻结协议](protocol.json)

历史诊断使用旧 16 篇论文的检索范围。第一题检查 1,001 个任务响应的证据，第二题检查旧三臂均答对的 Python 目标语言。它们各占一个首发顺位，单列于独立组的 48 道题之外。[历史题目与范围](../qa-first-response-20261114/reader/protocol3.json)

在独立组，分别用 30、18、48 作有据正答、正确拒答和合计首答正确率的分母，引文精确率使用全部返回引文作分母。证据命中要求实际原块内出现完整标注段落。比较配对得失时，每个问题以同一官方题号连接两臂，原始 HTTP 失败留在相应分母。[验收规则](acceptance.md)

运行以下命令可根据官方 TRAIN 和冻结合集复验样本、排除边界、先后顺序、历史范围与原始标注。扫描边界由本地留存文本决定，外部记录、已删除数据、无法精确匹配的改写及不透明二进制记录未覆盖。

```powershell
.venv/Scripts/python -m benchmarks.public_rag.evidence_retention_cases
```
