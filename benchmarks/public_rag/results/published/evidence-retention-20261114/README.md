“数据由 VLSP 2019 提供”的材料。按 API 契约这算误答。此问的两段引文
本身可溯源，也支持该背景事实。[逐题评分与配对得失](review.json)

负例中的正式作答按官方标注计数。评审同时检查所引原文，发现部分
官方负例仍可从论文充分回答，原方案有 3 例、候选有 4 例。保留原始
分母，也在逐题评分中标明该冲突。两个 Astra 评审对 100 种匿名答文

对同一问题，A 用 BGE 给 20 个原块打分。B 保留整块分，再用同一个
BGE 给块内每对相邻句打分，把最高的句对分与整块分取平均。每个句对
都在同一段内，单句成段时保留该句。句对评分时只取标题后的具体问题，
整块评分、候选召回和读者仍使用完整问题。两臂都按最终分选六个
原块，读者看到原文、位置和文档标识。

## 1,001 题为什么漏掉

QASPER 论文 1707.06939 的第 7 块（从 0 编号）覆盖原文字符
7,000–8,200。块里的两句先交代工人完成 1,001 个任务，其中对照组
496 个、实验组 505 个，再说明所有回复的收集时间。核对旧有 16 题，
CPU 复算的前六顺序逐题一致。此题的原块由融合候选第 15 升到 BGE
整块第 10，分数 −1.631。第六名的分数为 −0.433，排第一的是另一次
评分任务的原块，里面的 4,300 是质量评分数。旧读者据此表示无法确定
主实验的回复总数。

候选方法给这两句和原块合并评分后，第 7 块升至第 3，仍发送完整
原块。保留论文标题做句对评分时它排第 6；仅在整块评分时去掉标题，
它排第 4。在 10 道已曝光正例里，双句方案和去标题整块两种方法都
让六段内完整标注证据从 4/10 增至 6/10。各块分数、来源字符位置、
其他方法和逐题结果可独立核对。[开发重放](development/replay.json)

在这次真实 HTTP 首答里，整块方案仍然拒答。双句方案回答总数
1,001，对照组 496、AUI 组 505，引用 [3] 正是上述第 7 块；
原先答对的 Python 语言对照题两臂都答对。

## 独立题的计量口径

独立 48 题来自 48 篇公共 QASPER TRAIN 论文。全部 30 个正例都有原文
标注；按固定的 1,200 字符块和 200 字符重叠，其中 20 个完整标注段
能落在一个块内。因此该指标的切块上限是 20/30（66.7%）。若答案
或等价事实只需其中一句，仍可按实际返回引文判为正确。证据指标、
完整正答、正式拒答和引文支持分开计算。历史两题另用原 16 篇论文。

## 回执核验

100 次真实用户首答共发出 112 个阿里云模型 POST（含 12 次入口自带的
引文校正）。供应商 HTTP 均返回 200，用户端 99 次 200、1 次 502。
100 个读者输入各含六个原块，逐一与前置检索回放、官方语料字符位置
及实际发出的模型输入核对。包括历史对照的 157 条引文均验证到原块。
独立题端到端中位耗时为 3.52→3.96 秒。[运行与用量](execution.json)
· [原文、模型输入与两次检索对照](verification.json)

仓库根目录执行以下命令可从已归档的请求和裁决重算百分比、引文和
得失题，无需模型或数据库。

```powershell
.venv/Scripts/python -I -S benchmarks/public_rag/results/published/evidence-retention-20261114/verify.py
```

完整原文复核还需要官方 QASPER TRAIN 文件。从仓库根目录运行：

```powershell
$d = 'benchmarks/public_rag/results/published/evidence-retention-20261114'
$q = 'data/external/rag-public-20261021/qasper/extracted/qasper-train-v0.3.json'
.venv/Scripts/python -m benchmarks.public_rag.evidence_retention_verify --protocol "$d/protocol.json" --live "$d/retrieval" --retrieval-only --qasper $q --out .scratch/retention-dry-review.json
.venv/Scripts/python -m benchmarks.public_rag.evidence_retention_verify --protocol "$d/protocol.json" --live "$d/live" --compare-to-dry .scratch/retention-dry-review.json --qasper $q --out .scratch/retention-live-review.json
```
