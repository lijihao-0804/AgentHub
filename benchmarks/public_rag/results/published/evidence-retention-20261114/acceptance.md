# 六段证据重排验收

起点是本地 `main` 提交 `8f385b5`。在独立题产生回答前固定本规则。
用第 1,001 题及已曝光开发样本选择方法，随后冻结候选实现。独立题的
参考答案、标注证据、问答回执均不进入排序器。每题两臂从同一个
知识快照、同一问题、同一个前 20 候选池出发，各送六个完整原块。
原方法使用当前整块重排。候选方法用证据句调整原块排名。两臂使用
同一模型档案、系统提示、引文校验和输出额度。

使用 QASPER 公共 TRAIN 的问题、论文和答案所附证据进行开发验证。
同一题的一对结果算作一个样本，题数与实际请求数分别报告。
[QASPER 原论文](https://aclanthology.org/2021.naacl-main.365/)

|指标|统计单位和分母|
|---|---|
|标注证据召回率|可答题中，至少一段完整标注证据落在模型所见六个原块之一的题数 / 全部独立可答题。分别报前 20 和最后 6 段；另报前 20 已命中题的保留比例。|
|有据正答率|首个 HTTP 答复完整回答问题、各项事实被所引原文支持的可答题 / 全部独立可答题。|
|正确拒答率|官方无答案题中，HTTP 200、无引文、明确返回证据不足的题数 / 全部独立无答案题。另报错误作答和 HTTP 失败题数。|
|首答正确率|完整有据回答的正例数加正确拒答的负例数 / 全部独立题。502 或其他失败计入分母。|
|引文准确性|能支持至少一项所附事实的引用 / 全部返回引用。另检查原文、版本和位置，并审查整答是否含无据断言。|
|原有正确题保留率|候选继续完整答对或正确拒答的原正确题 / 原方法实际答对或正确拒答的题。正负例各报配对得失。|

候选进入默认问答路径需要独立题上的六段标注证据召回提升，首答正确率
至少持平，原有完整正答与正确拒答逐题保住，无新增错误作答，
引文准确性未下降，引用均能回到原块。历史两题单列，检查数量题的
实际输入、答复和所引句子，并检查原先答对的对照题。报告首个
HTTP 请求与物理模型调用数，包括现有引文校正的调用。
对相同问题做配对比较，同时报告分母、百分点和得失题数。

句子评分与整段评分结合的实验参考
[Yilmaz 等，Cross-Domain Modeling of Sentence-Level Evidence for Document Retrieval](https://aclanthology.org/D19-1352/)。
实验在本项目的问答入口测量这一做法能否保住有答案的原段。
