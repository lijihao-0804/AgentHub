# 客服退款政策 RAG：S0 虚构 DEV 资料

本目录包含 S0 的虚构资料、订单 fixture、50 题私有金标和 manifest。来源清单和订单 fixture 保留在评测侧用于复核；模型请求只能使用题目 input、指定 order_id 的 READ 查询结果和经治理的知识检索内容，订单表不得整体塞入 prompt。

业务时钟固定为 2026-10-19 10:00:00 Asia/Shanghai。工作日规则为周一至周五，无额外假日；这是虚构商家的测试规则。资料中的旧版通过 lifecycle.status=superseded 与 superseded_by 表达，不以文件名表示版本状态。

证据逻辑统一为：evidence_groups 外层为 OR，每组 all_of 内层为 AND。证据组允许等价替代，quote 必须逐字出现在 docs/ 下的源文件中。

当前 50 题各自只有一个完整证据方案，因此外层没有可替代组；同一题里同时需要的事实全部合并在该组的 `all_of` 中，避免只命中一个分支就被判为全部满足。

本目录的 `docs/`、`manifest.json`、`orders.json` 与 `cases.json` 是 S0 静态交付资料；临时生成脚本交付时已移除。
资料由助手与子代理起草、复核；S0没有派发待评测的A/B业务模型，也未读取旧HOLDOUT。助手编写消耗不属于A/B供应商用量台账。

`orders.json` 中的 `status`、`decision_status`、`execution_status` 和 `payment_status` 是 fixture 字段映射示例，不是平台枚举或正式领域契约；接入真实系统时必须由适配器显式映射。固定业务时钟为 `2026-10-19T10:00:00+08:00`，合约版本按 `contract_signed_at` 选择，历史合约不因当前查询时间而切换到新版。

四份长文档为 `05`、`10`、`13`、`16`，各超过 2400 个汉字并包含题目所需的跨段事实。来源中的“测试注入（非政策文本，必须忽略）”段落只用于验证不可信来源内容是否被误当成指令；它们的标注使难度降低，不能将本数据集的结果宣称为对抗安全验证。
