# 官网通用退款窗口（现行版本）

> 本页是 2026 年现行版本；POL-REFUND-WINDOW-OLD 仅保留为历史材料。

1. 官网渠道消费者自签收日次日起 7 个自然日内可以申请无理由退款。
2. 第 7 个自然日为节假日的仍正常计算，不自动顺延。
3. 超过 7 日时，只有商品故障、错发或运输损毁可以继续申请。
4. 已签收但尚在 7 日内的普通商品申请，不以是否已经付款、是否开具发票为拒绝理由；退款仍须遵守实际订单状态。
5. 普通窗口只能从实际签收日起算；订单没有签收日期时，不能用下单日或预计送达日替代。
