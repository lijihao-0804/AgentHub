# 测试用冲突收费条款

> 本文件故意包含同一现行范围内的矛盾条款，用于验证客服是否会保留冲突。

## 退货运费

1. 第一节称：无理由退货运费一律由买家承担。
2. 第二节又称：除大件和定制商品外，普通订单无理由退货运费全部由卖家承担。
3. 以上两节都是 active 状态，且都声称适用于普通订单；没有自动覆盖规则，也没有按客户等级区分的说明。

## 检测费

4. 退款政策中的费用条款声称：经检测无故障时收取 30 元检测费。
5. 售后服务页同时声称：无论检测结果如何，检测服务免费。
6. 两条没有版本关系、适用范围差异或优先级说明。若客户要求精确收费，应说明资料冲突并建议人工复核，不得任选一条报给客户。
