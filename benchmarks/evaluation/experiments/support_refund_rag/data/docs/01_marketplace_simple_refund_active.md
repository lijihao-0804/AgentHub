# 第三方商城普通商品退款窗口（现行版）

> 虚构测试政策。金额单位为人民币（CNY），业务时区为 Asia/Shanghai。
> 本页自 2026-06-01 起替代 POL-CHANNEL-MARKETPLACE-SIMPLE-OLD，旧版 7 日窗口不再适用于本版生效期。

## 窗口与包装

1. 第三方商城普通商品自实际签收日次日起 14 个自然日内可以申请无理由退款；周末计入 14 日，起算日不计入。
2. 无理由快速退款要求提供的外包装完整；已拆除外包装的商城商品应转人工，政策没有承诺这种申请自动通过。
3. 商品故障、错发或运输损毁的申请不受无理由 14 日窗口限制，但仍须提交对应证据并经过核验。
4. 支付渠道只决定退款原路返回方式；选择售后政策以订单来源渠道为准。
