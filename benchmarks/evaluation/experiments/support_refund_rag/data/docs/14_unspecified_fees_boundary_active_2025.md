# 未说明费用的处理边界

1. 本文件只规定未说明时不要猜造的证据边界，不构成一份完整收费表。
2. 检测费、二次包装费、跨境税费、分期手续费、加急费和上门取件费等费用，只有在订单、商品页或对应政策明确金额及适用条件时才能报给客户。
3. 任何金额服务费都不能仅凭常见做法推定；不得使用 5 元、10 元、商品价格 10% 等未由证据支持的固定数。
4. 保证金与退款不是同一概念。订单有保证金记录并不表示保证金已经退还，也没有给出保证金金额时不能猜造。
5. 系统返回运费、服务费或税费字段为空时，应说明记录未提供该金额；可以把查询结果转人工核对，但不能声称费用为零。
