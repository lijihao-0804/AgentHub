# 首次模型回复、拒答与引文的配对验收

产品基线为 `ab2b5b046da86bb2b0bd0eb65f7bab3a59eff239`，北京 `aliyun-rag`，模型 `deepseek-v4.1-flash-1017`，温度 0，最多输出 256 token。使用生产 `PROMPT_JSON` 问答入口、既有证据预算和正式引文校验。仅切换首答系统提示；两臂沿用同一纠正机制。提示、题目、来源、答案和判分代码在独立样本派发前通过 Git 固定。

## 诊断与原题保护

历史的 W3C 11–14 题均留下了两笔供应商回执、两次输出类型以及最终拒答判定。历史存储策略没有保存第一次和第二次回复的可见正文。诊断在相同公开表格、分层表头和原提示上重新观察四题，区分拒答标志、正文、引文列表与实际校验原因，并与候选的首次回复逐题比较。候选另行经过原先 10 道可答题，使用原冻结答案和源单元格判分。这 14 题属于开发诊断。

## 独立题

选用 100 个不同的文档和问题，50 题可完整作答，50 题在各自绑定的文档中缺少所问信息。任务范围是就指定文档回答问题。每题的两臂共享文档、修订、快照以及检索和重排设置。使用真实上传、切块、索引、检索、问答路由及模型网关。先后顺序按题平衡，单臂只提交一次首次 HTTP 请求。原始证据、可见答复和供应商回执保存在本地实验目录，仅公开派生结果与复核信息。

主要终点为第一次物理模型回复。JSON 或引文合同不合格、输出截断、执行错误都计失败。正确拒答须表达确实缺少所需证据、状态为拒答、正文无引文标记且返回空引用列表。有答案时检查回答值、单位或关键限定，并确认引用摘录支持所答事实。分别报告可答题答对率、可答题值与引文联合正确率、应拒答题正确拒答率、全部 100 题严格正确率，以及带引文作答的支持率与分母。接口内部执行纠正后的最终结果另行统计；同时列出纠正次数、供应商尝试数和费用。对自动判分存在歧义的等价表达和额外主张，按相同标准复核两臂并保留自动口径。不得基于候选结果改写金标或替换问题。

## 决策与费用

本轮目标是提高首次正确拒答。只有该指标和整体首答有实际收益、旧样例保护通过、已答对的独立题没有退步，且引文支持与最终正确性没有退步，才将候选合入 `main`。逐项列出首次和最终的配对进退，特别核对可答题的误拒答。一个版本的 100 次首次 HTTP 请求，连同另一个版本共 200 次；每次最多一次内置纠正。独立组最多 400 笔供应商请求。W3C 基线四题及候选十四题另计，最多 36 笔。每次按峰时未命中缓存的最高用量预留 0.018432 元，本轮总预留上限 8.036352 元，低于 30 元。以完整回执的输入、输出、缓存命中和北京时间峰谷费率核算，遇未知即停，不补跑。上轮未确认的费用不混入本轮。[北京费率](https://help.aliyun.com/zh/model-studio/deepseek-v4-1-flash)
