# 改变首轮生成提示的独立确认

上一轮在 335 份旧输入上修复了 8 个严格首答，但 64 道新题的首次正确拒答仍为 10/32。另行设计的扩大文本识别范围的离线原型，在 10 个隐含值压力例中误拒 7 个，未进入产品。此次直接检验模型能否在第一次生成时正确选择实答或拒答分支。

## 唯一干预

基线为主线原有系统提示。候选追加一次生成指令，先判断现有证据能否回答所问的任何部分。有依据的否定、零、范围、文档原话和部分答案都须保留事实及引文；整题确实不可答时只输出与问题语言匹配的简短拒答 JSON。两臂都关闭上一轮的首答后处理和实验性 v1 契约，使用同一个生产解析器和普通纠正路径。只改变 system 消息，两臂的 user 消息、知识快照、实际可见证据与编号、模式、模型、温度 0 和 2,048 输出上限均固定。两种系统提示分别产生真实的供应商回复。

## 观察与门槛

- 全新的中英文独立题 48 道，每种语言 12 道可答、12 道应拒。两臂均走 `POST /api/v1/knowledge/query` 和北京 `deepseek-v4.1-flash-1017`。新题使用隔离的真实上传、入库、BGE-M3、Qdrant 检索和重排冻结选段。
- N035、W13 两个版本、2hop__8556_47169、B097、R092、B006 共七份点名输入，以第一轮同证据、同上限、已确认的线上基线为对照；候选重新生成，单列这七份的基线重放和候选真实调用。
- 首答、终答及引文支持沿用第一轮的盲评标准。无效格式或引文留在严格正确率分母。逐语言检查原正确转错、应拒未拒和有依据实答误拒。原始供应商文本、完整用量和定位引文留在本机。
- 进入完整历史保护之前，独立组的严格首答正确数、首答正确拒答数必须均有净增。中文、英文的首答和最终阶段均不得发生原正确转错，有依据的实答不得被改成拒答。可答子集的受支持实答数、有效实答的总体引文支持率均不能下降，纠正次数不能增加。点名组须保住两道原正确实答，五份应拒输入全部首答正确。任一条件失败即封存结果。
- 条件满足时，进一步对原 335 份历史输入和首轮 64 道题中已正确的输入进行真实候选回归。同一输入的多份旧回复保留各阶段既有正确性的并集。覆盖 390 份不同输入，重叠的七份点名候选可复用本次已核验的结果。全组通过且零退步，才将本轮生成提示的产品改动合入 main；未运行的保护项不得视为通过。
