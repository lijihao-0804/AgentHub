| 报告条目 | 改动 | 复核结果 |

## 3. 八组推演与交互

| 推演 | 改进重点 |
| --- | --- |
| atomic-claim | 一步可高亮多条交接边，明确请求 → 数据库条件更新 → 获胜者；不暗示两个执行者都取得资格 |
| gateway-visible | 区分 Gateway、Runtime、浏览器可见性，显示备用模型接管的条件边；浏览器尚无文本不等于允许透明回退 |
| approval-twin | 决定/执行双状态；成功与未知分别终止；未知结果不能盲目重试 |
| version-freeze | 发布、新 Run、恢复旧 Run 的时间切片；具体绑定身份与冻结对象分别展示 |
| evidence-journey | 证据 A 的可见卡片，跟踪候选、重排、投影与最终消息，区分命中与实际准入 |
| wiki-lineage | 来源修订、编译、publication、AgentVersion 分层；区分撤销后的新执行阻断与历史证据保留 |
| memory-stages | 固定 M2/M3 证据卡；预算排除不画成 INVALIDATED，TOUCH 不画成实际 USE；重放读取保存的 ID/hash |
| experiment-freeze | 修正完整比较终点；缺 case 的实验与新实验的前提、分母和身份分开 |

通用修改：场景和步骤本机保存，返回时保持暂停；重置明确回起点；SVG 重绘恢复键盘焦点；提供可聚焦的交接名称与分支条件列表；统一步骤编号；小节、场景、步骤可定位和分享；章节导航支持浏览器前进后退。打开源码或档案说明会暂停推演，关闭后可继续；运行中切换减少动态效果偏好也会暂停。
