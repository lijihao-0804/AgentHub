## 费用缺陷及修复

新运行实例恢复审批 checkpoint 时，局部 `usage_records` 未恢复审批前模型调用记录。因此 WAITING_APPROVAL 不显示已花费用，恢复后只统计后半段；配置美元费用限制时还可能错误返回 `AGENT_COST_UNMEASURABLE`。

修复恢复 checkpoint 中的累计记录，在成本守卫前加载；等待审批时也持久化累计 token 和成本。图结束路径同步累计计数。未提供 usage/price 的轮次保留未知记录，避免将部分费用当完整费用。

三条独立集成测试覆盖：批准后新实例恢复、拒绝后新实例恢复、费用限制拒绝下一次模型调用；重复 resume 不增加调用。修复前真实断言失败见 `approval-usage-repro3.xml`，修复后相关集成检查通过见 `approval-usage-fixed.xml`。前两份复现记录是导入/驱动配置失败，未用作产品缺陷证据。相关流式测试子集退出时输出两个未关闭任务告警；随后的全量回归未再出现，不能据此声称专门修复了告警。

全量单元及集成回归 1207 通过、4 跳过、0 失败、0 错误；真实退出码 0，证据 `usage-rag-all.xml`，包括新增 RAG 来源观测测试。4 个独立 worker 用例已在前一轮真实专用环境单独通过，默认套件仍有环境跳过。全量 ruff 与 diff 格式检查通过。本轮不修改前端，前端 gate 不适用。
