# 共享证据组装：实施与评测结果

2026-10-23。实施范围来自[源码架构决策](AgentHub-RAG源码架构对照与改造决策-20261023.md)。**工程切片已完成；开发评测未通过质量或非劣门槛，默认基线保留，本轮结束。**没有继续扫参数，也没有开启新的确认集。

## 结果与决定

MuSiQue-Ans 官方 train 中此前已暴露的固定 160 题、143 个共享支持原文组，包含题目提供的全部干扰段落。基线是上一轮已验收的 `rag_records_v1`、RAG 预算 8000，不是历史上被通用 4000 预算截断的路径。三个组在本轮使用相同的新答案指令重新调用模型，不能与此前不同样本/指令的 39.39% 确认成绩直接比较。

| 指标 | 已验收基线 | 新紧凑视图 | 相同证据的紧凑诊断 |
|---|---:|---:|---:|
| 答案 token F1 | 47.86% | 45.69% | 45.32% |
| 答案 EM | 39.38% | 38.13% | 36.88% |
| 最终段落证据召回 | 81.15% | 81.15% | 81.15% |
| 完整支持段落集 | 61.88% | 61.88% | 61.88% |
| 观测输入 tokens / 请求均值 | 2270.45 | 1160.64 | 1160.64 |
| 证据 payload bytes 均值 | 6246.84 | 3602.15 | 3602.15 |
| 请求 P50 / P95，毫秒 | 803 / 1337 | 703 / 1297 | 733 / 1156 |

主比较 F1 差值 **-2.17 个百分点**；按问题配对、共享原文分组的 5000 次 bootstrap 95% 区间为 **[-6.10, +1.68] 个百分点**。区间不能证明普遍变差，也不能满足预定的 -3 个百分点非劣下界。输入 tokens 下降 **48.88%**、P95 比值 0.970、有效输出及证据门槛均通过，仍不足以宣布整体验收通过。

预先登记了两条验收路径：质量提高至少 3 个百分点且区间为正；或 F1 非劣、输入节约至少 15%、请求 P95 不超过基线 1.2 倍。两条都未通过，冻结选择为基线。门槛没有按结果放宽，没有重选格式、提示词或预算，没有消耗额外 200 题确认曝光。

完整[机器决定](../../benchmarks/public_rag/results/evidence-plan-20261023/acceptance.json)、[开发报告](../../benchmarks/public_rag/results/evidence-plan-20261023/development-answers-1/report.json)、[预登记协议](../../benchmarks/public_rag/results/evidence-plan-20261023/protocol.json)保留全部分母和失败。

## 已实施的架构切片

- 新增共享 `EvidencePlan`：把模型阅读内容与完整来源注册表分开；模型读取短引用编号、原文 snippet、标题、必要生命周期信息和位置数据。完整 snapshot、knowledge base、revision、chunk 身份及得分保存在执行状态侧。
- 检索器的新显式路径按实际渲染视图计算预算，不再让模型看不到的原文尾部和完整 DTO 元数据占用阅读预算。检索分数、排序、工具默认 5 / 最大 10、1000 字符摘要边界不变；没有合并块以隐藏原子证据数量增长。
- Agent runtime 使用随执行状态递增的短编号，引用身份不依赖 provider 调用 ID。最终 ContextBudgetPolicy 保留完整记录、计算消息开销，再核验实际可见正文及注册表；模型节点明确返回收紧后的映射，供检查点保存。
- Citation QA 提供显式内部接入，共用同一视图/注册表组装函数；保留原正文字符上限、数字引用、严格结构化输出能力门槛。默认旧路径保留，未新增公开问答路由字段。
- 独立 DeepSeek 审阅后补齐空白正文拒绝、位置字段白名单和畸形搜索结果失败关闭。完整 locator 仍在私有来源记录里，模型只接收支持的标量位置字段。

主要源码：[共享组装](../../packages/knowledge/evidence_plan.py)、[来源投影](../../packages/knowledge/evidence_records.py)、[可见映射核验](../../packages/agent_runtime/evidence_registry.py)、[runtime](../../packages/agent_runtime/runtime.py)、[检索器](../../packages/knowledge/retrieval.py)、[Citation QA](../../packages/knowledge/citation_qa.py)。

仅在显式 `retrieval_config.evidence_projection="compact_v1"` 且配置合法 `context_budget_bytes` 时启用；发布校验拒绝不完整配置。新字段缺省/None 不改变原配置。代码保留为实验选项，[预设](../../benchmarks/public_rag/evidence-plan-presets-20261023.json)明确标注未通过开发验收，不能作为默认推荐。没有发布业务 AgentVersion、修改模型能力或重建索引。侧表目前属于 Run 检查点状态，不是新的公开引用查询 API。

## 为什么没有提高召回或准确率

160 题中新旧路径的最终来源及正文相同，说明这些题主要受 5 个原子块与原排序选择限制，压缩表示没有新增互补支持段落。格式变紧凑会改变模型输入，却不会自动把缺失的推理链补上。

原计划的“相同证据诊断”在本样本与新方案的实际消息全部一致。因未在执行前合并重复输入，额外产生了 160 次同输入请求；费用记录完整保留，这些结果只能描述生成波动，不能算另一算法或更多独立问题。即使 temperature=0，也没有据两次结果不同宣称服务绝对确定。这是本轮执行中的可避免开销，后续应在请求派发前复用相同消息的诊断结果。

这次证据支持的结论是“表示开销明显下降，质量非劣尚未成立”，不能写成“RAG 准确率优化成功”。下一种质量方法需要真正改变互补证据的阅读单元/选择方式；不再围绕本格式反复调整预算或提示词。

只有很小的结构覆盖变化，没有新的 QASPER 答案 API 评分，也不是盲测或显著改进证明。见[回归汇总](../../benchmarks/public_rag/results/evidence-plan-20261023/qasper-exposed-regression-1/summary.json)。此前宽上下文离线 84.39% 不能混入这个真实 5 块口径。

## 验证、费用与边界

69 个不同的定向用例在分批检查中通过，覆盖新视图、错误引用/位置、预算及消息开销、跨调用编号、最终可见映射、发布配置、真实方法的检索选择、旧路径和问答能力守卫。相关格式检查和差异空白检查通过；没有新增哈希盘点、GPU/API 单元测试或反复全库回归。[验证记录](../../benchmarks/public_rag/results/evidence-plan-20261023/validation.json)说明各批重叠，不能将重复执行累计成独立用例。

审阅修正后再次离线回放，480 份生成消息与实际 API 请求输入逐项相同；QASPER 的 2010 份紧凑视图也满足最终校验。因此保留原生成成绩，没有为修正再次付费调用。

实际共 **480 次请求**：471 VALID、9 已知 provider 拒绝、UNKNOWN_OUTCOME 0。每一问题—方案对只尝试一次，失败保留且答案计零；观测 total tokens **735,829**，9 次用量未知，不按零补齐；没有价格快照，不估金额。延迟只计增量答案请求，不是完整 Run/SLO 加速。

检索使用冻结 BGE 分数及受控快照/向量 I/O，通过真实检索选择、工具、runtime observation、ContextBudgetPolicy 和 provider 消息转换后调用固定 `deepseek-v4.1-flash-1017`。不覆盖 live SQL/Qdrant、真实授权、检查点数据库、历史/记忆、多次自主搜索或中文业务。不是平台 Formal Experiment；执行与最终源码有范围限定的压缩包，保留原有未提交工作，不以新的哈希测试替代证据。

本里程碑收口：实现可审查、实验可复核、默认未推广；不继续这一格式方向的参数迭代。
