# 中英文首答、拒答与证据交付

在 100 道新题上，阿里云真实问答的首次严格正确由 77/100 升到 99/100，最终由 96/100 升到 100/100，首次正确拒答由 27/50 升到 50/50。R005、R027、R089 均恢复英文首次拒答。旧题 R092 和新题 B006 的候选都在首次回答时漏写正文引文标记，触发了事先约定的逐题保护门槛。两题最终均有正确且受引文支持的答案。候选保留在实验分支，主线继续使用原配置。[合并门槛](../../benchmarks/retrieval/experiments/bilingual_refusal_100/protocol.md)

首答逐题改善 23 道，全部为正确拒答；退步 1 道，净增 22 道。B006 问 ABC 未播的四集《Shadow Chasers》由哪个电视网播出。两版首次都答对 Armed Forces Network；候选 JSON 声明引用 1，正文漏了 `[1]`，第二次才补全。50 道可答题的候选、重排、首次实际发送的模型消息均含完整金标依据，两个版本逐题收到完全相同的证据。证据到达后的首答严格正确率因此分别为 50/50 和 49/50。这批题每题只有一篇短文、一个块，50/50 的实发到达率只适用于定向问答。

最终改善 4 题，无退步。B044、B063 的主线答复已承认缺少观测站发送间隔、收购价款，却写入相关背景引文并返回 `insufficient_evidence=false`。B039、B086 的主线都到达输出上限：前者只返回一部分英文 JSON，后者无可读答文；最终分别返回 `CITATION_QA_INVALID_MODEL_OUTPUT` 和 `MODEL_BAD_RESPONSE` 的 HTTP 502。候选在这四题均首次正确拒答。另 19 道缺证题的主线首答因拒答带引文而失败，均经内置纠正成功。新题两版分别 119、101 笔云调用，费用为 0.2239248、0.1560960 元。[逐题结果](../../benchmarks/retrieval/experiments/bilingual_refusal_100/results/reviewed-rows.jsonl) · [汇总、语言分组与配对变动](../../benchmarks/retrieval/experiments/bilingual_refusal_100/results/reviewed-summary.json)

## 已曝光问题的回归

R005（冰球馆最高天花板）、R027（吉祥物服装设计者）和 R089（夺冠分差）全部恢复。新候选从同一模型发回的第一次可见答复均为 `Insufficient evidence to answer this question.`，状态为拒答，正文无标记、引用列表为空。最终 HTTP 原样交付，每题只有 1 笔云请求。上轮候选在同一原文和同一问题上给过中文拒答。

对旧 100 题保留原工作区内的文档、块 ID、修订和冻结快照，逐题核对与上轮所发的用户消息相同。回归保护的是**旧两版中任一版曾经成功**的题目，包括使用提问语言。按此口径，旧 100 的保护分母是首答 98、最终 99。候选本轮首答 99/100，最终 100/100；全部 50 道缺证题首次英文正确拒答。R027、R089 的首答改善，R092 的首答从成功变为失败。该题的模型第一次正确答出“数据整合”，在 JSON 的 `citation_ids` 里列了 1，却漏写正文标记 `[1]`，接口纠正后才成功。此前正确的最终答复全部保住。[旧 100 的逐题保护评分](../../benchmarks/retrieval/experiments/bilingual_refusal_100/results/protected-100.json)

另一组 W3C 表格复测仍为 10/10 可答题值与引文正确、4/4 缺证题正确拒答，均为一次调用。旧组只保存了上轮首次可见答复、校验得分和前五块摘要；本轮复核依据为重新发送同一公开表、相同前五段与本次实际发送/引用的行列。这 10 道可答题实际引用的数据单元格均对齐。本轮盲评还发现两个未被这些答案引用的纯表头摘录存在一字符定位偏差，即模型可见文字完整，但偏移切片有误。[WAI 14 题回归](../../benchmarks/retrieval/experiments/bilingual_refusal_100/results/protected-wai14.json)

## 新题与主线路径

从 Git 固定的 `a81e88ea4ed77a258ec00f54add052f416fac8c6` 发起所有真实请求。对照为远端主线 `ab2b5b0` 的 `PROMPT_JSON`，候选为新的按问句选择语言的提示。问句的可判语言用于首次生成，找不到足够依据时给出同语拒答样例；保留明确的否定答案和有依据的部分答案。未指定输出模式时的 `JSON_SCHEMA` 不在本轮变更范围。未对模型的可见首答做语言后处理。历史保护集与新题的费用独立核算。

100 个问题各绑定一篇新来源，中文采用 CMRC 2018 的中文百科段落，英文采用 MuSiQue 的英语百科段落。中英各 50 题，每种语言各含 25 道可答和 25 道缺证题。针对 1,016 个可追溯历史文件、上轮 100 题和源数据问句排除交叉。材料最长 1,078 字节。它检验中英文指定文档问答和拒答，不能替代面对混合长文档库的端到端质量估计。实际入库、检索、预算、引文校验和网关均走应用；本地隔离库、进程内 Qdrant、测试身份和同步 worker 使配对固定到同一快照。[样本及剔重](../../benchmarks/retrieval/experiments/bilingual_refusal_100/source_freeze.json) · [冻结门槛](../../benchmarks/retrieval/experiments/bilingual_refusal_100/protocol.md)

100 对均调用北京区域已配置的 `deepseek-v4.1-flash-1017`，温度 0、输出上限 256 token。不同臂交错运行，逐次核对真实发送的问题、编号证据和固定提示。候选中的 50 道英文题使用英文模板，46 道中文题使用中文模板，其余 4 道按通用跟随问句语言规则执行。评审隐藏版本与首次/最终标签。两名 Astra 评审各核对 50 题，首轮共核对 214 份去重后可读的答复，其中包含结构无效但可以判断语言的内容。评审逐份核对所问事实、实际编号摘录和语言，并记录失败理由；首轮无未裁定项。机器初筛保留独立记录。[盲评规则](../../benchmarks/retrieval/experiments/bilingual_refusal_100/rubric.md) · [自动评分](../../benchmarks/retrieval/experiments/bilingual_refusal_100/results/automatic-summary.json)

检查原始输出时发现，常规 JSON 解析未提取一个在字符串中间截断的可见答文，按冻结规则该片段仍可判语言。对整批原始记录统一重扫，仅新增 B039 主线首答这一项，交由第三名 Astra 在隐藏组别与阶段后独立判定。原有 214 份判定逐字节保留。最终覆盖 215 份不同的可读答文，补录只改变该条语言判定，首次内容、引文、结构与严格得分仍为零，最终接口仍为 502。以上均为模型辅助盲评。

本机完整单元套件 3,603 项通过。双语运行器通过了真实 PostgreSQL、BGE、问答 HTTP 和模拟模型传输的 4 次请求冒烟，包含 2 次纠正；另用上轮真实模型的原始可见输出完成 114 条本地回放。这些离线检查的答复没有混入云测分母。[同行开源参照、648 题 FiQA 召回与消息证据实验](fiqa-message-recall-20261118.md)

补上截断答文的盲评读取后，重新运行双语测量、历史回归、问句语言三组单元测试，46 项通过。最终校验还比较了两次盲评投影的全部 200 条逐臂记录，仅 B039 的首答语言和补充审阅信息发生变动。Ruff 检查通过。
