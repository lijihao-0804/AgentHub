# AgentHub Memory M4：QMSum 评分与恢复修正

日期：2026-10-28。本记录针对既有 M4 研究脚本，不是产品摘要上线或质量验收。

## 发现与修正

- 已完成但不合格的摘要不能被当成“没有 C 候选，因此只运行 B”。新的计划把它记录为 `C_SUMMARY_INVALID`，保留失败原因，停止该题的 B/C 生成；摘要观察缺失或仍有未完成项时不进入答案阶段。
- 配对统计现在区分计划配对、两臂均有可用响应、只尝试一臂、尚未开始、已知失败、结果未知和响应无法核验。失败、未知及无法核验统计是按原因计数：同一两臂配对可能包含不同原因，类别之间不保证互斥。零有效配对时不能计算或宣称答案准确率提升。
- 试验结果恢复绑定冻结输入、供应商实际请求和保存响应。旧账本缺少请求及结果绑定时，新恢复流程将其标为无法核验，不重发，也不把它计为新的有效观察。摘要和答案分别检查冻结文件是否曾被保存。账本不保存提示原文或 API 凭据；这些一致性检查用于发现意外错配，不提供针对同时修改账本和结果文件的认证或防篡改保证。
- Windows 出现短暂文件占用导致本地账本原子替换失败时，有限次重试该本地文件操作；持续失败仍停止，保留之前状态。它不重试外部模型请求，也不改变未确认调用的预算保留规则。

## 历史证据与边界

冻结 QMSum 样本共 12 题：Committee 4 题因许可排除，Academic 4 题因 B 组预算阻断，Product 4 题的固定摘要调用均未得到可用摘要；其中两题还出现模型实际输入超出声明工作窗口的情况。结果记录和原因见 [QMSum 数据及调用记录](evidence/context-policy-m4-20261027/qmsum-preparation.md)。上述四次真实响应发生在新绑定协议之前，仍按原始执行证据记载，不得追认成新协议验证过的结果，也不能更换提示后重跑这些固定候选。

现有七次阿里云调用的忙时全价估算总额为 0.306040 元，实际账单未查询。本次评分和恢复修正未新增模型调用。有效 B/C 答案配对仍为 0；语义正确率、真实使用收益和端到端净费用均为未验证，而不是零准确率。纯词面参考分数不能代替关键事实、条件、否定、引用支持等语义审阅。

四道 Product 题来自两场会议，同一会议内的问题共享转写，不能当作四个独立会议样本。即使以后获得这类配对答案，也应按会议报告分组结果并明确样本量，不能用题数夸大统计把握；现有有效配对为零，更不能计算提升置信区间或做显著性结论。

本地测试使用独立文件账本及模拟响应，验证摘要失败不能产生不平衡答案、首臂和次臂失败的分母一致、旧结果或冻结输入缺失时不重派、响应被意外改动时不接受，以及预算文件短暂占用和持续失败的边界。测试不代表生产共享预算已接入，也不证明真实模型摘要质量。
