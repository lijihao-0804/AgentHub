# QMSum M4 受保护发言：模型调用前主代理来源审阅

本记录与 `qmsum-protected-turns-v1.json` 在本轮 QMSum 摘要或 B/C 答案产生前冻结。审阅从固定上游 QMSum 训练集的 `online_projection` 读取问题、自然顺序的会议发言和 speaker；未读取参考答案或相关片段标注。先用问题相关词定位，再阅读相邻发言核对角色、条件、纠正与讨论进展。它是主代理的抽样审阅，不是独立人工盲审，也不保证覆盖所有重要事实。

序号是 QMSum 对应 `meeting_transcripts` 数组的零基下标。在线 C 视图保存所选发言的完整内容、序号和 speaker；B 保留完整会议。给 C 增加人工式选取原文的工作量应在结论中注明，不能将差异全部归因于摘要模型。每题的具体原文选择见同目录 JSON；没有摘录模型输出，也没有修改冻结选题。
