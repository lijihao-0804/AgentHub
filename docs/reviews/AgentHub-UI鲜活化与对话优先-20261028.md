# AgentHub 前端：鲜活化与对话优先（2026-10-28）

## 方向修正（按产品反馈）

产品定位是**智能体**，因此：

1. 配色必须**鲜活**，不要沉默的高级灰；
2. 侧边栏要**精简**，不堆一长串；
3. **对话是主页面**，其余信息可收起/隐藏。

## 配色：采用 DSH 的真实品牌色系

从本机已安装的 DSH 主题包（`@deepseek-ai/dsh-client-ui-theme`，实现 = 开源 deepseek-harness）
读到的令牌：主色 `--dsw-static-deepseek-500:#4176e6 / #5686fe`，onboarding 品牌渐变为
**蓝 → 紫 → 青**（`#3964fe → #8b76f6 → #6dccff`），界面字体 Montserrat。

据此定义「鲜活智能体控制台」：

- 深墨底 `#0b0e14` / 表面分层 `#121722 / #171d2a`；
- 主色 **鲜活蓝** `#5b8cff`，辅以紫 `#a78bfa`、青 `#22d3ee`；
- 品牌渐变 `--gradient-brand: linear-gradient(135deg,#5b8cff,#8b76f6,#22d3ee)`
  用于宝石标、认证卡/首页发丝线；
- **主按钮改为蓝→紫渐变填充**，成为唯一"有电"的元素；
- 状态色更鲜明：成功 `#34d399`、警告 `#fbbf24`、危险 `#fb7185`、信息 `#60a5fa`。
- 浅色主题同步（主色 `#2563eb`）。

## 结构：侧栏精简 + 对话优先

- 侧栏只保留 **对话**（研究/故障/分析/支持）与 **运营**（仪表板/运行/审批）两组；
  智能体、知识库、工具、评估、设置折叠进一个「更多」开关，默认收起。品牌点击回到首页。
- 应用工作台默认**收起右侧详情栏**（`sideOpen=false`），对话占据主列；详情可一键展开。
- 对话输入框聚焦时带蓝色光晕；用户消息气泡沿用强调色底。
