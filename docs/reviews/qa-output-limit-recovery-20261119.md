# 57 次问答 502 的输出上限对照

固定证据和提示词后，阿里云北京工作区的 `deepseek-v4.1-flash-1017` 在 2,048 档恢复了 55/57 次 HTTP 200。另两条在单独登记的 8,192 档都能返回有效拒答。按冻结金标，57 条最终严格答对 21 条。独立新题的严格首答从 23/61 升至 31/61，但两道新题和 W13 的一个证据版本丢失了原先正确的首答拒答。实验未达到零退步门槛，保留现行模型配置。旧实验的 256 来自问答测试档案，本机已配的阿里云路由本身是 2,048。[冻结方案](../../benchmarks/retrieval/experiments/output_limit/protocol.md) · [运行登记](../../benchmarks/retrieval/experiments/output_limit/registration.json)

## 旧失败的两种原因

57 是旧实验的失败请求数，覆盖 38 道题和 49 份不同消息。同一题按旧实验原有两种选段分别保留。旧 39 次空回复都由模型在思考阶段用完 256 个 token，正文为零。另 18 次已经生成正文，推理用去 167–250 个 token，正文只有 5–88 个 token，JSON 尚未闭合。两类调用都有供应商成功回执，此处的 502 由 AgentHub 网关或引文答案解析产生。

| 原失败组 | 重测 256 最终 HTTP 200 | 2,048 首次 JSON 可解析 / 最终 HTTP 200 | 2,048 严格首答 / 严格最终 | 单独升档后累计 HTTP 200 |
|---|---:|---:|---:|---:|
| 空正文，39 条 | 11/39（28.21%） | 39/39（100%） / 39/39（100%） | 12/39（30.77%） / 12/39（30.77%） | 39/39 |
| 截断 JSON，18 条 | 5/18（27.78%） | 16/18（88.89%） / 16/18（88.89%） | 9/18（50.00%） / 9/18（50.00%） | 18/18 |

只看本次 256 档仍为 502 的输入，空正文组在 2,048 档恢复 HTTP 200 的比例为 28/28，严格恢复 9/28。截断组分别为 11/13 和 4/13。同样的消息、温度和上限再次提交也会出现不同输出，因此同时保留“全部原失败”和“本次低档仍失败”两个分母。[逐条结果](../../benchmarks/retrieval/experiments/output_limit/results/row-status.jsonl)

例如，`2hop__40626_475429` 的 baseline 六段指出谁在 1801 年引入高压蒸汽机，却没有写明他的死亡地点。`2hop__365241_754472` 的 candidate 能把专辑连到 Andre Nickatina，人物段只说他“来自旧金山”，没有写出生地。按金标，这两条都计作误拒。固定送达证据的实验可以定位缺失的事实，无法把缺失进一步归因到切块、候选召回或重排。

2,048 档仍失败的两次都耗尽了全部输出预算且正文为空。主试验封账后，另行登记的 8,192 档从同一问答入口运行这两条，证据与提示词相同。心理学期刊出版方题 `2hop__806218_14904` 在纠正后仍拒答，耗时 3.05 秒。Ibn Muqla 出生地题 `2hop__839424_160978` 直接拒答，耗时 34.29 秒。两题金标均为可答，严格首答和最终均为 0/2。追加的 3 次供应商调用与主对照分开核算。16,384 档触发条件未出现。[升档登记](../../benchmarks/retrieval/experiments/output_limit/tail-registration.json) · [两题逐次结果](../../benchmarks/retrieval/experiments/output_limit/results/tail.json)

## 保护回归和合并结论

R092 两档均首答、最终全对。B006 在 256 档纠正后答对，2,048 档首答、最终均正确。W13 的两个证据版本在 2,048 档都需纠正才能获得有效拒答，其一从 256 档首答正确退步，另一份则从 256 档的 502 恢复。

271 份保护输入中，历史上已严格答对且有同输入基线的首答保住 184/224（82.14%），最终保住 251/257（97.67%）。267 份普通保护输入复测高档并对照历史记录，另 4 份点名输入两档均在线实测。历史默认来源涵盖 R100、B100、W14；W 组的 14 条历史默认输入无可复用的同输入阶段分，能匹配到其他已审历史记录的阶段按该记录比较。所有未评分阶段和 40 条首答退步的逐项 ID 见汇总的 `protected_stages`。[保护输入、逐题进退及合并门槛](../../benchmarks/retrieval/experiments/output_limit/results/aggregate.json)

| 最终退步题 | 输入数 | 归因 |
|---|---:|---|
| `2hop__106185_77138` | 1 | 郡名答对，引文区分主题公园及园内的方舟模型，回答混用了两个实体。 |
| `2hop__636562_141689` | 2 | 题目问鸟类的科，两份实答均给出有引文支持的 Turdidae，冻结金标 Zoothera 是属名。两份按原口径记失分。 |
| B097 | 1 | 正文说明材料没有教室间数，却带引文并返回 `insufficient_evidence=false`。 |
| R005 | 1 | 模型正确判断高度缺失，正文中的双引号未转义，JSON 解析失败。该次正常结束于 `stop`，没有触发纠正。 |
| W14 | 1 | 拒答荧光绿海报正确，却额外断言全表只有棕褐与黑白。该次提供的节选确实只显示这两类，完整表还含全彩行；按整表断言计错。 |

即使剔除科属金标冲突，仍有真实的拒答字段、引文和格式退步。此次保留 BGE-M3、当前证据选择及现行默认档案，未向产品加入自动重发或自动升档。若要改善首答，实际发生的“正文已拒答但引文违规”应与 502 分开衡量。
