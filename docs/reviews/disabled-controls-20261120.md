本次复查以 `f663f37` 为起点，按上次 41 个页面状态的 DOM 记录及配套截图重新编号。同一个按钮在三个页面出现时分别取证。原始巡检使用组织所有者账号，截图只能说明采样时的页面状态。本轮另用组织成员兼工作区查看者做权限对照。

验收使用本机 Edge、Next.js、FastAPI 和 PostgreSQL。写操作使用可写测试工作区，读取服务端记录核对结果。对加载态的检查暂停尚未送出的真实请求，观察控件后再放行。会话使用本机固定应答模型。

## 实点发现并修复的问题

- **权限提示过早。** 工作台、对话和智能体详情在权限请求完成前曾向所有者显示角色不足。现在区分正在读取、读取失败和已确认只读。给权限 GET 注入一次 503 后，页面保留禁用保护；点击重试，真实 GET 成功后恢复可写。真实查看者依然受限。
- **运行历史显示前一个智能体的版本。** 在两个智能体间切换并延迟第二个版本请求，修复前仍能点开第一个的版本，修复后等待当前结果。智能体目录、版本目录各自遇到 503 都可就地重试，真实重试均返回 200，运行表和已有深链接仍能使用。切换工作区后，浏览器没有在新工作区请求上一个智能体的版本。
- **快照切换后，旧结果重新出现。** 暂缓快照 A 的真实检索响应，选中 B，再放行响应。修复前概览重新显示 A 的 ID，修复后保持 B 的初始状态。自动回归还覆盖了 A → B → A、旧失败晚于新成功、切换知识库后三种情况。
- **会话续期可能继承另一账号的权限。** 同源标签共享刷新 Cookie。现在每个请求绑定发出时的会话，续期返回另一用户时使原标签的登录失效，迟到的响应不能覆盖新登录。合成的前端回归覆盖同账号续期、更换账号、切换工作区和旧 401 晚到。

## 验证边界

所有业务写入均在本机测试工作区完成。发布、新建、发送和运行已核对 API 或数据库记录。新建普通会话和调试运行未在通用审计表产生对应条目，两项验收使用其各自的持久化记录。付费模型调用为 0。

第 2 项的快照选择、空快照检索和旧结果竞态由共享 QA 的真实 HTTP 服务验证。补充的非空快照检索将浏览器的检索 POST 接入隔离的同一 FastAPI 路由，使用相同的 QA 数据库、生产混合检索代码、内嵌 Qdrant 和固定编码、重排器。非空快照的五个检索阶段各得到 1 项，页面显示的原文、块 ID、修订 ID 均与库内一致；切回空快照得到 0 项。共享 QA 的独立 Qdrant 端口在验收时拒绝连接，未验证该环境下 BGE-M3 的检索质量。

自动回归入口为 `node scripts/test_web_regressions.cjs`。八组前端回归和独立输出目录的 Next.js 生产构建均已通过。回归覆盖组件真实处理函数，并包含本次补充的权限、版本和快照乱序用例。真实浏览器记录、合成账号和原始回执保存在本机。
