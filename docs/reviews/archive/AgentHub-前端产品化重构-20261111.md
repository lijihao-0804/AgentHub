验收状态：**本里程碑通过，按单里程碑规则收口。**

## 设计与范围

面向配置、运行和管理智能体的工作区使用者。页面首先回答“在哪里、能做什么、当前发生了什么”，技术证据按需展开。

- 画布：雾灰 `#f4f7f8`；内容表面：白 `#ffffff`；正文：深墨 `#172e35`。
- 导航：深海 `#142e35`；主要交互：青绿 `#087f75`；风险与状态保持独立语义颜色。
- 字体：可本机渲染的清晰无衬线中英文字体；界面正文与密集数据分级，数字使用等宽数字。
- 布局：固定的产品地图、工作区上下文和一个主要内容画布。日常应用、构建资源、运行治理分组可见；深层工具从对应资源页进入。
- 风格原则：以导航结构和内容密度形成识别度；清晰边界、适量留白、有限强调，避免装饰渐变和虚构指标。
- 保留全部已有路由、会话、业务操作与用户未提交变更；新增前端体验使用既有接口。

```text
产品导航       工作区 / 页面上下文                         账号与偏好
              ──────────────────────────────────────────────────
工作台         页面标题、说明与主要操作
应用           筛选 / 数据摘要
构建资源       内容列表 / 编辑区 / 会话工作台
运行治理       对应的状态、空态和恢复操作
设置
```

### 真实数据与关联修复

独立 QA 账号以组织 MEMBER、工作区 VIEWER 加入已有 Research 工作区。密码和认证状态不写入仓库；截图、运行日志和 JSON 报告保留在本机忽略目录，未上传到外部服务。

首轮浏览器矩阵包含 16 个场景 × 2 种主题 × 2 种语言 × 3 个宽度，共 192 个组合：108 个通过、84 个失败。所有组合均通过页面横向溢出与顶部控件碰撞检查；失败保留在 `final-report.json`，没有覆盖为成功结果。

首轮失败暴露了两项实际服务端投影问题，并完成最小修复：

1. 只读用户的 turn 正文已按权限脱敏为 `null`，读取响应却要求字符串，导致 HTTP 500。GET 专用响应投影现在允许空正文，提交契约不变。真实数据的 49 个会话、65 轮记录读取返回 200，内容字段均保持脱敏。
2. 实验响应要求 `dataset_id`，ORM 实验只保存 `dataset_version_id`，原直接校验导致 HTTP 500。现在通过受工作区约束的批量只读关联取得所属数据集，保留原响应校验与权限；列表及详情真实 GET 已返回 200。未执行实验或访问 holdout 题目。

同一实验响应投影也用于既有创建与 finalize 完成后的返回值，避免操作已成功却在响应校验时产生 500。领域写入、冻结、权限和提交顺序不变；这两条写入路径仅用 FakeService/FakeSession 测试响应，没有实际执行业务写入。

另修正浏览器检查对明确预期的权限 403、上一页导航取消请求和动画中间帧的归类。没有忽略当前场景的 500、资源缺失或请求失败。
