## 来源纠正

退款实验的 16 份政策、50 份订单和 50 题均为助手起草、助手复核的虚构 DEV 材料，不是公开商家政策或公开人工标注数据集。依据为实验 `source-review.md`、manifest 与执行报告。

保留原实验作链路诊断及边界回归，不继续把修订这些虚构材料作为主要质量优化方向，也不以其成绩代表实际客服能力。已观察到的原文遗漏、状态越界仍是有效反例；其发生频率和外部代表性未知。历史快照、评分和报告不改写。

项目此前已准备公开数据，见 `benchmarks/public_rag/sources.json`、`README.md` 和已有公开 RAG 报告：SciFact、QASPER、MuSiQue 已在本地存在，且部分数据已经用于开发和评测。应先复用已有适配和暴露记录，避免再造一套无来源语料。

## 选择

| 数据 | 原文与标注依据 | 用途与限制 |
| --- | --- | --- |
| CMRC 2018 | 维基百科段落、专家人工标注问题和答案片段；[论文](https://aclanthology.org/D19-1600/)、[官方仓库](https://github.com/ymcui/cmrc2018) | 下一轮中文基础基线首选。原任务是给定段落的阅读理解；改为多文档检索时必须标为派生 RAG 设置，不能冒充官方榜单成绩。不能单独验证客服政策、拒答或多跳能力。 |
| QASPER | 真实 NLP 论文；领域人员提问，另一批人员作答并提供支持证据；[论文](https://aclanthology.org/2021.naacl-main.365/) | 复用本地已有资源，测长文证据覆盖与答案支持性。先查已有 paper ID、问题 ID 和暴露记录，已开发过的论文不能重新叫独立确认集。 |
| T2Ranking | 搜索日志查询与中文段落排序任务；[官方仓库](https://github.com/THUIR/T2Ranking) | 需要单独校准中文召回/重排时再用；相关性标签不等于生成答案或完整政策条件的金标。暂不并行铺开。 |

本轮先选 CMRC 2018 做中文基础验证；长文方向沿用 QASPER，分里程碑推进。均不生成、改写或翻译标准问题与答案来冒充原始数据。

## 下一步实施边界

1. 从官方资源获取公开 train/dev 和官方评测代码，记录版本、下载来源、许可及文件校验；保留原始问题/答案/来源 ID。不读取隐藏测试集、不自行补造测试标签。官方仓库标示 CC BY-SA 4.0；获取时一并保留许可和署名要求。
2. 先用 train 中按预定规则选定的 50 题做 DEV 冒烟；按文章/原始 context 分组，重叠文本去重。独立确认集合先登记 ID，不提前阅读答案调参。若存在跨划分文本重叠，记录排除规则和影响。
3. 两种设置分别报告：给定原文的阅读基线、在预先定义且保留干扰文档的语料库中实际 RAG。不能只把每题正确原文放进独立知识库，再称检索成功；答案标签不得入库。库规模与抽样方式必须随报告披露。
4. 走生产上传、入库、检索、观察和上下文准入链路，记录目标原文能否召回、答案片段是否实际可见、原始 EM/F1、引用支持性与失败计数。官方 EM/F1 用作任务分数，派生引用指标单独列出。
5. 首轮冻结当前配置，只建立可信基线，不同时改提示、检索参数或模型。开始付费前将调用数与费用纳入明确的实验预算；不自动把旧退款实验的预算授权挪到新实验。
6. 公开基准也可能已进入基础模型预训练。用真实检索证据覆盖与给定原文对照辅助解释成绩，不能声称模型绝未见过题目。中文抽取基线通过不代表真实客服验收通过。

当前只完成来源核实和替换方案；尚未下载 CMRC、建立新知识快照或取得新成绩。后续正式质量改进以公开来源、固定任务和独立标注为依据；自造案例仅补充工程边界。
