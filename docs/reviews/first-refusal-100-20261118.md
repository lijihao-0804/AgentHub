# 引文问答的首次拒答与纠正

候选让 19 道原本在拒答时携带引用的独立题全部首次通过。按冻结的语义与引文规则，100 道题中首次严格正确从 80 道升到 100 道。另有三道英文题收到中文拒答，其中一道原本首次即可正确用英文拒答。按用户要求保护已经答对的题，候选保留在实验分支，`main` 维持原提示。

两臂的 100 对模型输入证据逐题相同，50 道可答题的全部标注依据都已送到模型。99 对成功响应的检索阶段顺序可逐项对齐。R012 的基线在用满 256 个输出 token 时仅给出不完整 JSON，接口返回 502，未附阶段轨迹；其第一次实际请求携带的两段证据仍可核对。候选在同一证据上回答了 GSA 表达图像物体间的相对几何关系，有对应引文。这一个正例不足以说明可答题总体有稳定提升。

基线的另 19 个首次失败全部是拒答带引文，均调用模型纠正了一次。候选让这 19 题全部首次通过。按冻结语义规则，20 题首次新对，0 题退步，80 题持平。最终结果多对 2 题，分别为 R012 和 R027。R027 的基线纠正后虽正确拒答设计者姓名，却把海豹的**物种**对球队的指代说成**名字**的由来；盲评和独立复审均判这项补充陈述缺少支持。[盲审汇总和逐题进退](../../benchmarks/retrieval/experiments/first_refusal_100/results/semantic-summary.json) · [逐回复判分及理由](../../benchmarks/retrieval/experiments/first_refusal_100/results/reviewed.jsonl)

### 回答语言与合并决定

生产系统提示明确要求使用提问语言。本轮新题全部为英文。候选对三题正确地判断了证据不足，给出的完整拒答句却是中文。这三题的处置、引用、事实语义符合冻结标准；用户读到的语言发生了变化。补充审计保留了原有评分，另外按“语义、引文、提问语言都正确”计算交付结果。

| 英文题 | 原提示 | 候选提示 | 对交付的影响 |
|---|---|---|---|
| R005，Ingalls 冰球馆的最高天花板有多高 | 首次以英文正确拒答 | 首次以中文正确拒答 | 首次、最终各退步一题 |
| R027，谁设计了 Lou Seal 的服装 | 首次拒答带引文；纠正后的英文解释混淆了名称和物种 | 首次以中文正确拒答 | 语义改善，计入语言后两版均未全对 |
| R089，Hueytown 夺冠时赢了多少分 | 首次拒答带引文；纠正后以英文正确拒答 | 首次以中文正确拒答 | 最终退步一题 |

计入提问语言后，首次严格正确为 **80/100 → 97/100**（18 题新对、R005 退步），缺证题首次正确拒答为 **31/50 → 47/50**，最终严格正确为 **98/100 → 97/100**（R012 新对，R005、R089 退步）。这三次真实的语言偏差阻止了默认切换。比较结束后未对这 100 题调提示或补发云请求。[补充语言审计](../../benchmarks/retrieval/experiments/first_refusal_100/results/language-audit.json)

自动判分保留原样，首次严格正确为 79/100 与 96/100。两臂的 R013 均使用了有重叠的两段有效引文，机器评分的片段匹配未给满分。三条中文拒答未命中英语判分词式。R027 旧提示最终答复中有一条额外断言，仅通过字面拒答检查。逐项盲审和语言审计分别说明了这些差异。[自动汇总](../../benchmarks/retrieval/experiments/first_refusal_100/results/automatic-summary.json) · [自动逐题判分](../../benchmarks/retrieval/experiments/first_refusal_100/results/automatic-pairs.jsonl)

候选在 `PROMPT_JSON` 模式中给出无引用拒答的完整 JSON 样例，同时要求保留有依据的部分答案和否定结论。两臂使用相同的输出校验器和纠正机制；应用未指定模式时使用的 `JSON_SCHEMA` 路径在本实验范围之外。

旧组 10 道可答题的候选全部一次返回。冻结的字面判分为 9/10。第 10 题答对了 A5 海报为 Sepia，又引用另一行说明黑白款只列 A1、A3、A4。字面判分见到第二种颜色就扣分。以留存答复在同一问答路径作零付费回放，两条实际引用分别支持这两句话，按含义复核为 10/10。[原答复、行号与两种评分](../../benchmarks/retrieval/experiments/first_refusal_100/results/wai-control-10-review.json)

## 独立配对的设计

派发前冻结在 `50c7340f9c352919de3531c1b54126b909a63f4e`。100 个新问题各绑定一个不同的公开来源，其中 60 篇是 MuSiQue TRAIN 所收录的维基段落，40 篇是 QASPER TRAIN 的论文摘要。两类来源各自一半可答、一半在指定文档内缺少所问信息。针对项目可用的 934 份历史结果排除旧父题、文章、段落、论文和相同问句。原文最长 1,530 字节；这批样本检验的是有明确文档范围时的首答与拒答，不能据此估计长文、多文档召回或中文客服的线上表现。[来源与查重清单](../../benchmarks/retrieval/experiments/first_refusal_100/source_freeze.json) · [问题、金标及原文位置](../../benchmarks/retrieval/experiments/first_refusal_100/cases.json)

实验调用应用的 ASGI HTTP 入口 `/api/v1/knowledge/query`，使用隔离的 PostgreSQL、进程内 Qdrant、真实 BGE 稠密和稀疏编码、重排以及阿里云北京模型 `deepseek-v4.1-flash-1017`。测试身份和队列由运行器注入，实际使用产品的上传、入库、快照、检索、模型网关和引文校验。每题按交错顺序分别提交一次原提示与候选提示，比较送到模型的证据指纹。两臂均为温度 0、输出上限 256 token。[运行器](../../benchmarks/retrieval/experiments/first_refusal_100/runner.py)

每题每臂保留两份成绩：供应商第一次返回的可见回复，以及接口执行内置纠正后的最终响应。结构或引文校验失败的首次回复记错；纠正成功不回填首答。全部题的严格正确要求可答题的答案与引文同时正确，或缺证题作出合规拒答。带引文作答的支持率要求每条实质性主张均有相应引用，分母是该阶段实际带引文作答的数量。自动评分与隐藏组别后的逐项语义评分分别保留。[预注册门槛](../../benchmarks/retrieval/experiments/first_refusal_100/protocol.md) · [盲审规则](../../benchmarks/retrieval/experiments/first_refusal_100/rubric.md)

两名 Astra 评审各核对 50 道题。完全相同的问题、答复、状态和引文在组内及组间去重，共有 186 份有效答复需要核查。评审能看到金标、完整文档、实际提供的证据和引用位置，评审包隐藏了组别、阶段、系统提示和累计得分。不同提示的行文风格可能被辨认。这里报告的是按同一规则进行的模型辅助评审，未使用人工专家标注。

## 请求与费用

独立组 200 次问答产生 219 笔供应商请求，包含 19 次纠正，按回执计价 0.3620076 元。旧题诊断另有 18 次问答、20 笔供应商请求、2 次纠正，计 0.0867616 元。全轮有 239 份不同的确认回执，合计输入 174,007 token（其中缓存命中 38,656），输出 21,292 token，按请求时间和北京公开费率核算为 **0.4487692 元**。未确认请求为 0。金额为按用量计算的费用，实际出账以云账单为准。实验使用的两张公开源表和 100 个公开文档之外未提交工作区业务资料。[分组用量与对账指纹](../../benchmarks/retrieval/experiments/first_refusal_100/results/billing.json) · [阿里云计价说明](https://help.aliyun.com/zh/model-studio/deepseek-v4-1-flash)

## 离线复核

从仓库根目录可以直接用已公开的逐题判分重新算出两臂百分数和配对进退。下列命令无需模型或数据库。

```shell
python -m benchmarks.retrieval.experiments.first_refusal_100.summarize benchmarks/retrieval/experiments/first_refusal_100/results/reviewed.jsonl semantic-summary.rebuilt.json
```

实验执行时的完整单元套件为 3,559 项通过。另以新夹具验证了配对分母、证据一致性、逐次用量与预算中止，再用 9 项结算测试覆盖跨组重复回执、缺少确认、用量篡改等情况。真实 PostgreSQL 和 BGE 的小规模离线演练走过相同 HTTP 路由，随后才对冻结的独立题派发阿里云请求。[真实调用校验](../../benchmarks/retrieval/experiments/first_refusal_100/attempts.py) · [结算复核](../../benchmarks/retrieval/experiments/first_refusal_100/billing.py)
