# AgentHub 本轮缺陷收口补充报告

本补充对应 `AgentHub-前端产品体验审查报告-8138c7e.md` 与其阶段性修复报告。旧报告记录的是上一轮提交时的状态；本补充记录后续核对后发现并收口的缺陷。Playground 多轮会话、参数调试和模板库（FE-C-06/07/08）按用户决定暂不实施。

## 本轮收口

- **PE-12 审批闭环**：决定成功后在对应审批项内提示已保存，并提供返回来源运行的链接。
- **PE-06 门禁后续入口**：PASS 直接打开候选智能体版本对应的 Playground，并通过 `version` 参数锁定门禁评估的确切版本；其他门禁结果链接到该版本详情。
- **PE-30 焦点与层级**：焦点环支持 danger 语义色；topbar、浮层和 skip-link 的层级改用设计令牌。Playground 延迟格式例外继续按原注释保留。
- **FE-B-04 仪表盘数据消费**：补齐输入/输出/缓存 Token 均值、每次运行平均成本、审批决定与执行状态分布；趋势卡环比的零基线不伪报百分比，零变化使用中性箭头。仪表盘运行数、版本统计、趋势 tooltip 与成本样本计数统一格式化。
- **PE-11 只读呈现**：research 与应用会话均在权限不足或响应已裁剪对话内容时显示只读说明；限制发送、取消操作，并避免把服务端裁剪的空内容误显示成“无输出”。
- **FE-E-01 会话恢复**：重载后对等待审批、运行中和取消请求中的轮次继续轮询；切换线程或卸载时中止旧 SSE 客户端流，防止旧会话响应污染当前视图。
- **PE-10 收件箱发现新审批**：即使当前列表为空也持续轮询，并在页面重新显示时刷新。
- **PE-24 文案一致性**：补清留出集叙述与应用概览中的英文术语；新增的审批闭环提示提供中英文文案。

## 状态

本轮复核到的剩余缺陷已在工作区修改。没有实施 FE-C-06/07/08。按项目指示，本轮未运行测试或构建命令；结论仅依据代码与文案静态复核。
