## 修复：审批收件箱白屏（P0）

- 现象：`/approvals` 整页 "Application error…"，控制台 `Cannot read properties of undefined (reading 'some')`。
- 根因：审批接口返回**裸数组**，前端按 `{items,total}` 取 `page.items` → `setApprovals(undefined)`
  → 渲染时 `approvals.some(...)` 崩溃（与历史数据集白屏同类契约漂移）。
- 修复：`lib/api/approvals.ts` 的 `listApprovals` 归一化，兼容裸数组与 `{items,total}`；
  `app/approvals/page.tsx` 用 `page.items ?? []` 兜底。已实机验证：收件箱正常显示 3 条审批
  （含决策/执行状态、reason、技术参数折叠）。
