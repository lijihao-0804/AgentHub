# Wiki 工作台本地化修复

基于已合并 PR #11 的 main `fcafc83`。浏览器核查发现中文工作区的 Wiki 工作台仍展示整页英文，本次补齐简体中文和英文文案、表单与状态提示、空状态、权限提示及可访问名称，并同步知识工作台入口。

文案类型集中在 `wiki-copy.ts`。切换语言保留当前知识库、查询草稿及已加载状态，不触发写入或模型调用；服务端状态码、原始证据和标识符保持原值。编译、显式发布、重试、权限隔离、续期及工作区切换的既有行为继续适用。

已有 Wiki 回归脚本增加两种语言的实际 React 渲染和语言切换检查，脚本与 TypeScript 检查均退出 0；本候选 production build（包含类型检查）退出 0。构建使用本机已有依赖 junction，standalone trace 的 Windows symlink 限制不影响本地 `next start`，不将其称为可搬运的 standalone 发布包。没有重复本地全库测试、截图或文件哈希。远端 CI 与本地服务状态另以最终候选记录，本报告不预写通过。

开发使用用户指定的 DeepSeek 子代理；本切片的应用测试和预览未派发付费 provider 请求。开发子代理消耗不在项目研究费用账本中。
