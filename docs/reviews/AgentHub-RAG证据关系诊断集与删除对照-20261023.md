# 证据关系诊断集与关键证据删除对照

2026-10-23。**本轮已冻结开发诊断数据，完成原回答流程的真实 API 测量：有证据时答对 3/4；删除关键答案证据后正确拒答 4/4；两种条件都正确 3/4。**这是固定小样本的机制诊断，未验证新回答策略，不改变默认和此前确认成绩。

## 设计主线与开源依据

沿用“问题需求 → 证据覆盖 → 答案支持”的职责划分。本轮先把证据是否足够变成可以复核的对照条件，再决定研发方向；不把引用身份合法、答案字面出现或官方段落标注当作语义支持证明。

阅读了 [RGB 的实际 evalue.py](https://github.com/chen700564/RGB/blob/master/evalue.py)：`processdata` 在 `noise_rate=1` 时不提供正证据，评估逻辑另外统计拒答。这启发本轮把“有证据答对”和“缺证据停止”分开测量。本轮使用 AgentHub 已有原文及契约，采用成对删除指定来源记录的对照，没有引入上游代码、数据、提示或关键词式拒答判定；不是 RGB 复现，也不是其替换事实的 counterfactual robustness 测试。[RAGChecker](https://github.com/amazon-science/RAGChecker)对答案与上下文支持分开诊断的思路继续作为评估依据，没有增加在线语义判官。

## 冻结的数据具体是什么

完整保留上一轮 **32 道已曝光 MuSiQue train 题**的台账：原问题、官方 aliases、模型审阅的多标签意见、确定的阶段可见性观察和待裁决状态分开保存。模型初标不会自动成为参考答案。

其中选择关系清楚、且可以明确移除目标事实的 4 题作为首批成对诊断；另外 **28 题保持待裁决**。选择依据是原文关系与删除条件可核查，并包含已知普查失败例；不是随机总体样本，也不是 holdout。不得把它称为 32 题人工金标集或新的正式 DatasetVersion。

每对有两种条件：

1. **supported**：原来真正准入的消息、原文及顺序完全不变。记录问题目标、所需关系、逐字支持片段、原来源 ID 和服务器计算的位置。
2. **answer_evidence_removed**：仅删除包含最终答案事实的完整记录及对应 refs；保留所有其它消息、问题、原文、顺序、版本与生命周期字段。剩余材料仍可相关，但不能支持题目所需的具体答案。

没有编造问题、事实或替代段落，没有修改官方 aliases。负例标签表示“在只允许使用本次提供材料的策略下证据不足”，不表示现实世界没有答案。未把官方问题分解、关系标注、expected 标签或题目 ID 传给模型。

| 原问题主题 | 所需最终关系 | 删除后仍保留什么 |
|---|---|---|
| 非洲最大经济体的参议院议长 | Nigeria → Senate President，按来源时点 | 国家及经济描述，没有议长身份 |
| 南极海生普查的执行时期 | Census → carried out during International Polar Year | 南极地理定义，没有普查时期 |
| 与 Waukee High School 同州的 Shady Grove 所在县 | Shady Grove, Iowa → Buchanan County | 学校与 Iowa，没有 Shady Grove 的县归属 |
| Bear Creek 所在县的人口 | Pinellas County → 2010 population 916,542 | Bear Creek 所在县及其自身人口 1,948，不能代替县人口 |

所有时间相关标签按提供的历史原文解释，不是关于今天议长、经济排名或人口的事实声明。

## 复核、冻结与请求控制

一个使用用户指定 DeepSeek 的新上下文子 agent，未接触本轮生成结果，独立检查四对完整材料，4 对通过、0 对争议；8 条审阅引文都通过对应原 snippet 的精确子串校验。主执行者再次核对关系、删除效果、来源和时点范围。模型审阅看到了拟议标签，不是盲审；没有人类专家校准，不把这些标签包装成人工真值。

数据和协议在模型调用前冻结。首次冻结中的一项离线关系标签，将“最大经济体所属国家”关系的 subject 错写为 Nigeria；调用前改为 Africa，另存修订 2，旧版保留。全部 8 份模型消息、问题、证据、aliases 和预期条件与修订 1 相同。这不是看过输出后的改标或换题。当前数据为[frozen-dataset-v2.json](../../benchmarks/public_rag/results/support-dataset-20261023/frozen-dataset-v2.json)，[协议](../../benchmarks/public_rag/results/support-dataset-20261023/protocol-v2.json)保留修改说明。

两种条件同期发起，均使用原直接回答提示、`deepseek-v4.1-flash-1017`、temperature 0、thinking disabled、JSON-object、最大输出 256、一次调用、无重试或备用模型。相同 8000 证据预算、16384 上下文上限，由原 ContextBudgetPolicy 准入，逐项确认消息未被进一步裁剪。负例的实际文本更少是删除实验本身，不据此宣称性能或费用优化。

先验证第一对的两次输出结构均有效，再分派剩余 6 次请求。未知结果、错误模型和非 400 服务错误停止派发；所有在途请求等待完成。初始与删除条件均重新请求，是为控制本次证据对照中的服务时点差异；不混用历史正例来解释上下文删除效果。没有反复运行相同对照以挑选成绩。

## 真实结果

| 题目主题 | 完整证据回答 | 官方短答案是否匹配 | 删除关键证据后 |
|---|---|---|---|
| 参议院议长 | Bukola Saraki | 是 | 正确拒答 |
| 海生普查执行时期 | **2010** | **否；原文是 International Polar Year** | 正确拒答 |
| Shady Grove 所在县 | Buchanan County | 是 | 正确拒答 |
| Pinellas County 人口 | 916,542 | 是 | 正确拒答 |

完整证据的 token F1 和 EM 均为 **3/4**；删除条件的有效结构化拒答为 **4/4**，无依据交付答案 **0/4**；成对两项都正确 **3/4**。所有 8 个结果均通过共同的答案结构与可见引用 ID 守卫；引用 ID 合法没有阻止普查题答错关系。

正确拒答必须是有效输出，且 `unanswerable=true`、答案和引用均为空。服务错误、非法输出、未知结果和未尝试请求均不能当作拒答成功。所有计划对照保留，无失败删样本。

这里不计算总体准确率置信区间或显著性结论：四对经过选择、来源已曝光，删除的是整份关键记录，属于较清楚的缺证据情形；不覆盖事实藏在混合材料中、冲突来源、复杂拒答或开放检索。**4/4 不意味着项目拒答率已经达到 100%；3/4 也不是新的整体 RAG 准确率。**

## 已明确的下一研发方向

本批材料没有显示需要优先给每个问题追加通用拒答或语义检查调用。相反，在明确充分的原文中，普查题再次将 `carried out during` 和 `released in` 混淆；这个错误与候选不足、来源 ID、别名差异可以分开。

下一研究应围绕**所问关系与答案取值是否一致**扩充独立来源案例，覆盖执行/发布、对象/相邻对象、行政层级等差异，再验证一次有针对性的回答机制。只修好这一已知题不能证明方法有效。若扩充样本发现主要问题另有所在，再据证据调整；不要从一个失败案例直接泛化到全库图索引或通用多轮阅读。

本轮验收范围是“冻结可复核诊断数据、完成基线测量、明确评分边界”，不是提高总体质量。没有启动下一方法实验或新确认集，没有新增生产 reader、策略开关或业务 AgentVersion。此前已验收的互补选材方案及独立确认分数保持原样。

## 实现、验证和成本

[support_dataset.py](../../benchmarks/public_rag/support_dataset.py)检查成对来源、问题、别名、原文范围、refs 和生命周期保持一致，并分开计算有据答案、缺据拒答、无据回答和成对成功；[support_dataset_runner.py](../../benchmarks/public_rag/support_dataset_runner.py)记录全部请求、响应和用量。[8 项定向测试](../../tests/unit/test_support_dataset.py)通过，覆盖不受控文本/问题/别名变更、伪造引文、错误不能冒充拒答、剩余材料出现答案字面不能证明关系成立，以及缺失计划样本不能提分。没有新增哈希测试或重复全库测试。

本轮 **8 次答案 API 请求，8 VALID，UNKNOWN_OUTCOME 0，观测总 tokens 7,417**，全部用量可见。完整条件输入 4,327、输出 183 tokens；删除条件输入 2,835、输出 72 tokens。没有价格快照，不估货币金额；子 agent 审阅不在答案请求账本中，其编排用量不可见。前台任务 exit 0，运行约 6.14 秒，无后台作业。
