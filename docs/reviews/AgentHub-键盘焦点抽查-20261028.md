# AgentHub 前端：键盘焦点抽查（2026-10-28）

在 `/dashboard`、`/approvals`、`/runs` 用 Tab 逐项走查可聚焦元素，读取 `outline`/`box-shadow`：

- 绝大多数控件（跳转链接、导航、顶栏按钮、指标卡链接、表格链接等）均为 `solid 2px` 焦点环，符合预期。
- 发现：仪表板时间范围用的是自定义 `Select`，其触发按钮聚焦时仅边框变色、无明确焦点环（`outline:none` 且无 `box-shadow`）。
- 修复：`.select-control:focus-visible` 与展开态 `[data-open=true]` 增加 `box-shadow: 0 0 0 3px var(--accent-soft)`，与全局焦点环一致。
- 验证：Tab 聚焦时间选择框可见清晰蓝色焦点环。
