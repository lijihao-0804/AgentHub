# 首次拒答的两轮真实入口配对

两轮实验共使用 112 道互不重复的中英文新题。第一轮的后处理能修正五份已知失败回复，在 64 道新题上没有净收益。第二轮改变首次生成时的系统提示，48 道新题的纠正从 11 次降至 0 次，但有 17/24 道应拒题作为实答交付，严格最终正确率从 87.50% 降到 62.50%。两轮均未达到合并门槛。产品基线为 `deb28ec`。[第一轮分析与回执核算](first-refusal-contract-20261119.md) · [第二轮逐题结果](../../benchmarks/retrieval/experiments/refusal_prompt/results/row-status.jsonl)

这七份输入都以第一轮已确认、同证据、同上限、同系统提示的基线回执走真实接口重放，候选各自向供应商重新生成。严格首答均为 3/7，但正确题目发生交换。严格终答由 7/7 降至 4/7，五份应拒输入的正确首答由 1/5 到 2/5。第一轮后处理对更早的五份原始失败回复全部修对；只有重新生成时暴露出的差异能检验这种恢复是否稳定。

## 两个独立题集

严格正确要求答复类型、要点、语言及实答引用均正确。拒答须无引文。正确拒答率以所有应拒题为分母；引文支持率以有效实答为分母，要求每条实质性主张都能由定位到的证据支持。格式无效与引用矛盾留在严格正确率分母。首答在首次模型返回后计分，终答在接口返回时计分。两批题均为新编短文和场景，语义判定由项目内盲评代理完成。

| 独立组指标 | 第一轮基线 → 后处理，64 题 | 第二轮基线 → 新提示，48 题 |
|---|---|---|
| 严格首答正确 | 39/64 → 39/64（均为 60.94%） | 31/48（64.58%）→ 30/48（62.50%） |
| 严格最终正确 | 61/64 → 61/64（均为 95.31%） | 42/48（87.50%）→ 30/48（62.50%） |
| 首答正确拒答 | 10/32 → 10/32（均为 31.25%） | 7/24 → 7/24（均为 29.17%） |
| 最终正确拒答 | 32/32 → 32/32（均为 100%） | 18/24（75.00%）→ 7/24（29.17%） |
| 有效实答引文支持，首答与最终相同 | 29/32 → 29/32（均为 90.62%） | 28/30（93.33%）→ 37/41（90.24%） |
| 可答题被错误拒答，首答与最终相同 | 0/32 → 0/32 | 0/24 → 0/24 |
| 纠正次数 | 22 → 22 | 11 → 0 |

第二轮 24 道可答题中，基线 24 道全部答对且引文充分，候选 23 道。FP017 的原文说可请持有人更新纸本，候选额外断言这是唯一办法。另有五道原本正确的首答拒答变为实答。在 24 道应拒题中，基线第一次有 7 个正确拒答、11 个无效回复和 6 个应拒却返回的实答；候选第一次有 7 个正确拒答、0 个无效回复和 17 个应拒却返回的实答。模型把“能解释资料为什么缺这个值”也作为选择实答的理由，原接口的格式校验不会对这种回复再发纠正。

盲审复核纠正了 13 份材料的引文支持标签。有些回答把缺值解释标作实答，但找到的原文确实支持它对材料缺口的陈述，因此应计入引文支持分子。答复类型错误仍使这些题严格判错。复核保留了 FP017 的无据排他推断、FP002 的独奏间入场推断、FP006 的手机照片禁令等引文错误。修正后严格正确数及所有题的合并决定均相同。

| 第二轮独立子集 | 严格首答，基线 → 候选 | 严格终答，基线 → 候选 | 正确首答拒答，基线 → 候选 |
|---|---|---|---|
| 中文 | 14/24 → 15/24 | 20/24 → 15/24 | 2/12 → 4/12 |
| 英文 | 17/24 → 15/24 | 22/24 → 15/24 | 5/12 → 3/12 |

## 如何控制证据与费用

第二轮候选产品提交 `c22a4bb`，实验实现 `02b0c73`，付费前登记 `38bf10e`。48 个知识库上传 74 篇原文，经本地 BGE-M3、Qdrant、重排及选段后冻结。全部 74 篇进入各自的首轮消息，与所核对的 403 个历史题面及 930 段历史材料无归一化精确重复。同一语言内，可答、应拒两组的可见文档数分布一致。每题两臂分别进入生产 FastAPI 应用的 `POST /api/v1/knowledge/query`，重放固定的检索输出和位置；传入供应商的 user 消息逐字相同。北京 `deepseek-v4.1-flash-1017`、温度 0、输出上限 2,048 均固定。第二轮只改 system 消息，两臂各自获得真实回复，同时关闭第一轮后处理。盲评核对了 220 个首轮与最终阶段，其中 110 份不同的有效材料有 7 份沿用完全一致的既有判定，103 份新评。[冻结方案](../../benchmarks/retrieval/experiments/refusal_prompt/protocol.md) · [输入、控制变量与冻结指纹](../../benchmarks/retrieval/experiments/refusal_prompt/registration.json)

第二轮 110 次应用请求对应 115 次新物理调用。七份点名基线使用已付费且已确认的 11 份回执，四次历史纠正未重复计费。第二轮所有应用请求最终均为 HTTP 200。独立题的问答入口耗时中位数为基线 1.69 秒、候选 1.60 秒，P95 为 4.83 秒、2.83 秒（最近秩），包含所需的纠正，不含重新检索。累计 30 元预算已占用 **3.26662012 元**，其中包含历史两笔 UNKNOWN 的 **0.04906200 元**预留，余额 **26.73337988 元**。本任务新 UNKNOWN 为零。费用依据回执时间、输入、输出和缓存命中量逐笔核算，供应商结算账单另计。[北京模型费率](https://help.aliyun.com/zh/model-studio/deepseek-v4-1-flash)

按付费前冻结的顺序，开发门槛失败后封账，390 份不同历史输入的第二轮候选保护阶段没有启动。第一轮对 335 份固定历史输入做过离线保护回放，原正确首答和终答均无损失，该结果不能代替对这套新提示的验证。两套实验改动均保存在对应研究分支。

本地验证通过 160 项既有问答契约、入口、拒答保护和配对评分测试，以及 18 项提示词、执行器、计量与门槛专项测试。全仓 Ruff 检查通过。公开的 110 条逐臂记录已经与封账文件逐字节比对。
