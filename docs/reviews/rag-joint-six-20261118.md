# 六段联合选择能否保住两跳证据

**保留 main 的默认六段策略。** 联合选择让 48 道独立题的完整双跳从 30 道增至 35 道，同时丢了 1 道原本完整的证据。64 道真实问答的严格首答从 22 道降至 19 道，正确拒答从 9/16 降至 6/16。选择器及完整实验留在 `codex/joint-six-evidence`。

对照版本为 `4a0daa2`，联合选择器为 `eb0082c`。固定 BGE-M3 稠密向量、项目现有的词项稀疏编码、RRF、BGE 重排器、问题、读取提示和最多六段的约束。候选对重排池最多 20 个原块枚举不超过六个块的组合，综合重排分、问题词覆盖、跨来源的特征实体、同源续窗与文本重复。选中块按重排名次送入原问答入口，保留修订、块 ID 与位置。每个输出编号仍对应一个原块。入模前用原上下文预算再检查完整消息。正式新题出分后没有调整选择权重。[选择器](../../packages/knowledge/joint_evidence.py) · [冻结规则](../../benchmarks/retrieval/experiments/joint_six_review/protocol.md)

## 旧六题的定位

旧 24 题中，21 题在重排池里可以拼全两段官方原文，15 题在默认首条消息里仍然完整。逐一核对另外六题后发现，达尔文、路德宗和《Baby》丢的是包含次要信息的尾窗，回答所需事实已出现。旧金山金字塔、Depp 和 Ciales 丢了一个官方来源。其中金字塔问题的重排第 8 名同时给出了城市和建筑名，默认六格却同时容纳多处其它金字塔。Ciales 需要换入第 8、19 名才能拼全第二段，其中第 8 名就有关键事实。Depp 的官方段落只说明两人是共同父母，仅凭这一事实难以证实题目索取的婚姻关系。[六题的占位段、漏段、名次和替换方案](../../benchmarks/public_rag/experiments/joint_six_20261118/historical-six.md)

冻结后的候选在旧题回放中只补回金字塔，双段完整由 15/24（62.5%）到 16/24（66.7%），没有失去原有完整题。重放实际选择与消息预算的本机中位耗时从约 2.5 毫秒增加到 131 毫秒。这项计时不包含检索、模型生成或网络。[旧题逐项回放](../../benchmarks/public_rag/experiments/joint_six_20261118/old_replay.json)

## 样本与真实入口

正式样本含 48 道新的 MuSiQue 双跳可答题和 16 道官方不可答题，另外一题只用于核对付费回执。每题一个隔离快照、20 个原段，两臂共用该快照。不可答组各有 8 道缺首跳和缺末跳。48 道可答题里有 10 道的一个支持段超过 1,200 字符，没有两段都超过该长度的题。新题与已登记历史题之间没有重复问题、组成跳或官方支持正文。按历史已注册问题的所有原版变体比对，1,300 个新来源中有 287 个普通干扰段也出现过，其中正式可答组占 208/960。这组英文训练集的结果适用于本次固定候选条件。[样本注册](../../benchmarks/public_rag/experiments/joint_six_20261118/manifest.json) · [负例检查](../../benchmarks/public_rag/experiments/joint_six_20261118/controls.md)

调用经过 `POST /api/v1/knowledge/query`、本地 PostgreSQL、Qdrant、嵌入与重排器，再由真实供应商生成。基线和候选交替先发。质量评分依据首次物理回复与最终 HTTP 返回，逐条核实内容、语言和所引片段能否支持桥接及所问事实。无效输出计失败，拒答单列；引用支持率的分母是有效实质作答。历史保护组采用 R100、B100、W14 先前实验中任一已成功策略的并集，首答与最终各有 214 个受保护结果。历史提示策略的差异会限制因果归因。[问答入口和复现](../../benchmarks/retrieval/experiments/joint_six_qa/README.md)

首答的引文检查针对模型实际收到的编号原文。最终引文检查针对接口实际返回的摘录。基线遵循既有摘录长度限制，候选允许返回整个已选原块，所以若长块引用在两臂显示长度不同，最终支持率的变化还可能来自读者能看到的原文长度。[问答响应实现](../../packages/knowledge/citation_qa.py)

## 新题的两跳证据

64 道正式题完成 1,280 次文档入库，生成 1,342 个块。逐笔比对 128 条真实首次模型请求与冻结的预检，系统提示、用户消息、候选、重排分数、去重顺序、六个原块和引用位置全部相符。主组 48 题中，45 题的候选在六个位置以内就能拼全两跳，其中 37 题只需两个原块、8 题需要三个。余下三题的候选已不完整。两臂共同使用相同的 20 个候选，27/48 题发给读者的消息有变化。

## 历史回归和审核

R092 保留了 QA-SRL 标注流程中的 data consolidation，B006 同时给出 Armed Forces Network 和 4 集，两题均首答、最终正确且引文支持。历史 214 题在本轮候选的首答正确为 166/214（77.6%），最终为 210/214（98.1%）。按 R、B、W 分开，首答分别为 74/100、80/100、12/14，最终为 97/100、100/100、13/14。首答未保住 48 个历史成功结果，其中 45 题的新基线与候选消息逐字相同。最终未保住 R005、R038、R090 和 W13。前三题输出校验失败，W13 的正文承认没有退货量，接口却以带引文的实质作答返回。先前确认成功的读者提示与本轮存在差异，且没有为估计随机性重复发送相同问题，历史差异不能全部归因于选段。[所有退步题与逐项标记](../../benchmarks/retrieval/experiments/joint_six_review/regressions.json)

684 个题臂阶段形成 372 份不同的匿名评阅包。Codex 子代理和主代理按题面、金标和实际引用做语义盲审，同一答案及可见引文相同才复用判断。另对 39 条含数字的有效拒答核对了当时可见原文，未发现暗中给出所拒答的值或添加无据数字。抽取影片拍摄地时，剧情所在地不支持拍摄地点；制造者不能仅凭产品冠名推断；没有片名的演员名单也不足以独立支持题中指定的影片。表格数字命中时还要核对行、列和单位。此为内部模型同行复核，未新增人工金标。

有一题的金标与原文发生可核实的分类层级冲突。问题问斯里兰卡鸫的“科”，原文明列 Turdidae，金标却给出属名 Zoothera。两臂都正确回答了原文明示的科，主表按实际题意给分。若必须逐字遵循这条金标，两臂首答各减 1，为 21/64 与 18/64；最终各减 1，为 25/64 与 22/64。配对差和默认决策均相同。

选择器及引用问答相关测试两批共 101 项通过，覆盖六段上限、上下文准入、定位和冻结开关。离线回执夹具检查了成功响应及缺失用量、矛盾用量、重复回执、异常状态或传输中断；另按固定快照费率复算核账和正式账本。正式消息和公开结果可按登记哈希独立核验。[实发首请求验证](../../benchmarks/public_rag/experiments/joint_six_20261118/live-evidence.json)

全新题 `2hop__657848_91875` 由问答入口和阿里云各返回一次 200。唯一物理回执与唯一逻辑请求对应，输入 1,702 token，命中缓存 0，输出 186，无纠正。按北京时间忙时复算为 0.004892 元。此前已确认 1.2133176 元，两笔历史状态未明预留合计 0.049062 元，核账后累计占用 1.2672716 元。此前封存的请求没有重发。正式计价按 `deepseek-v4.1-flash-1017` 北京快照，未命中输入/缓存命中/输出忙时每百万 token 为 2/0.04/8 元，闲时为 1/0.02/4 元。核账题缓存用量为零，修正缓存单价对该题金额无影响。金额按物理回执和公布价估算，账户抵扣以供应商账单为准。[北京固定快照价目](https://help.aliyun.com/zh/model-studio/deepseek-v4-1-flash)
