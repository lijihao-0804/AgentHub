## 1. 最新执行约定

用户已授权M2～M5连续推进，并将原对话主模型改为Terra。保留其当前模型和思考设置，从工作树实际进度恢复；不要重做已完成M2，也不要把尚在运行的测试或子代理重复启动。先读已有日志和交付状态，再接手未完成项。

阶段仍串行验收，通过后自动进入下一阶段，不再等待确认。每阶段留下独立commit、测试证据与报告。用户授权覆盖旧文档中的阶段结束停止规则；没有覆盖模型能力、租户隔离、不可变版本、UNKNOWN_OUTCOME、来源和计费契约。

普通代码错误、测试失败、可修复迁移/环境/接口问题自行处理。实验负结果不等于施工阻塞：保留负结果、关闭未通过质量门槛的能力，再继续不依赖其收益的后续开发。不能把未验收的错误代码当作上一阶段通过。

真正阻塞指缺少无法恢复的授权/数据/凭据、无法安全确认的外部派发结果影响后续一致性、不可解决的并发写入冲突或必需基础设施不可用，且无安全替代路径。先收敛受影响链路并继续独立部分；只有剩余工作全部依赖它时才结束执行，报告阻塞证据、已尝试措施及所需最小输入。

不合并主工作区、不部署、不更改用户现有Agent默认或业务数据库。隔离环境的显式迁移和可恢复修复属于施工范围；不得删除用户数据。主代理负责集成，最多三名子代理并发，默认遵循AGENTS。至少十分钟间隔的主动进度查询规则继续适用，完成事件立即处理。

## 2. M3：token驱动历史、分级与确定性调度

### 2.1 输入和来源契约

在既有Thread来源/运行时模块上扩展，禁止并行实现另一个历史系统。最小来源单元包含作用域、稳定source ID、不可变revision或内容身份、顺序、水位、完整交换归属、原文可恢复引用、计数版本、是否允许摘要及原因。

- Thread读取先固定上界水位，分页在该范围内稳定排序；同时间戳用稳定ID打破平局。新消息不得挤入已冻结历史范围。
- 先统计候选完整来源需求，再分配；不能先只取最近10轮再判断是否触发。大历史流式计数或持久计数索引，不能每轮无限全表载入内存。
- 数据读取有页大小、最大工作量与明确不足状态；达到资源限制时不能伪称已经测量全部历史。恢复使用原来源范围及计数/策略版本。
- assistant工具请求与对应结果组成完整组；并行call及多个result不能拆散或错配。活动组和未决审批不得归入可摘要前缀。
- 原始Thread、工具artifact仍是权威来源；摘要引用不能越Workspace、Thread、权限或发布快照。

### 2.2 分级规则

| 级别 | 允许内容与行为 |
| --- | --- |
| 必须原样 | 当前输入、近期完整交换、活动工具组、权威权限/审批/动作状态、当前明确纠正；不经语义摘要 |
| KEEP_EXACT | 决定性原文、金额/单位/条件/否定/例外/冲突及无法确定摘要资格的材料；完整准入或明确缺据 |
| 可摘要已完成前缀 | 有可审阅资格依据的旧完成讨论/重复背景；原文保留，M3只规划，不调用摘要模型 |
| 按需来源 | 历史大artifact的已授权引用；只允许通过现有读取及权限机制恢复，不新增通用任意文件读取工具 |
| 可确定性省略 | 依据明确规则识别的精确重复或不在当前范围材料；保留归因，不用未验证语义分类器假装确定性 |

分级不把自然语言关键条件自动识别当作既成能力。不确定就KEEP_EXACT；未来提高可压缩覆盖另作候选验证。Thread摘要不会写入共享长期记忆。

### 2.3 计划器与运行时接入

实现可注入计数器的纯计划器，输入冻结能力/业务预算、完整来源组、已发布有效摘要引用和有界增长G；输出保留范围、整组淘汰、压缩资格、可用摘要、原因、裁剪前N及planned=N+G、最终准入视图和不足状态。

优先级：必须内容/活动组 → 相关KEEP_EXACT → 近期完整交换 → 已核验摘要 → 其他可选材料。所有池共用B_work，4K共享事实只是软目标，禁止各自借满总窗。Memory仍沿用M1冻结候选和完整原子准入；RAG引文与证据配对不能打散。

70/85/55使用M2冻结阈值。M3有压力但没有摘要时，采用事先确定的完整交换选择或明确不足；不可把已裁剪输入当成未触发，也不可引入隐式摘要。必须内容本身超限则停止该次派发并给出固定安全错误，不裁掉系统权限或用户句尾。

G只代表未包含的预期增长，不上传/不计费。最终每次派发仍经ContextBudgetPolicy对实际ModelRequest硬校验。计划器和真正发出的请求必须一致，trace默认只记计数/身份/原因。

### 2.4 M3测试与验收

行为覆盖：跨页相同时间戳、新消息并发写入、水位恢复、重复/缺失来源、空历史、大历史资源上限、工具组跨页与并行结果、必须块超限、共享池借用总限、memory-off、RAG引用、最新纠正、没有可压缩范围、70/85整数边界及G不重复计数。

用隔离PostgreSQL验证分页与恢复，fake provider捕获实际ModelRequest；M3不得发供应商请求。对比旧路径：关闭新策略的版本仍走兼容路径。验收必须展示一次“旧10轮裁剪隐藏压力，新路径在裁剪前识别”的离线证据，明确它是机制回归。

交付来源和计划器契约、最小运行时集成、受影响单测及集成原始结果、M3报告。主代理复核通过并提交后自动进入M4。

## 3. M4：摘要产物、状态恢复和单候选质量验证

### 3.1 最小产物与状态机

优先复用现有辅助调用/费用/队列/trace模块；只对缺少的持久状态增加显式迁移。

摘要job需保存Thread/Workspace、源水位/范围及hash、parent revision、压缩策略/prompt/模型与tokenizer版本、目标预算、唯一身份、执行权和状态、原始响应引用、验证结果及费用账本关联。摘要产物保存结构化内容、来源索引、revision/hash、验证器版本及发布状态。

具体状态名可适配项目，必须区分：等待、已claim未发、已发结果未确认、响应已持久化、验证通过待发布、已发布、已失败、过时/无执行权。请求超时不能推断未执行；结果未知不可静默重发。用持久dispatch intent与执行权校验收敛窗口，不承诺无法证明的exactly-once。

先持久化响应，再解析校验，最后CAS发布；失去执行权、权限撤销或源水位过时的worker不得发布。发布失败保留产物与已发生费用。checkpoint引用具体revision和原文范围，恢复不读latest。

### 3.2 首个压缩提示与验证

直接采用原调研方案第8节中文候选提示作为起点，存为明确版本；预登记后不边看结果边改。输入仅包括允许摘要的完整历史前缀、source索引、目标与预算。受保护事实由服务器另行原样保留，模型只能引用，不能拥有权限或工具。

输出结构至少有status、goal、decisions、supported_facts、conflicts、open_questions、completed_actions_refs、next_steps、omitted_source_ids。每项具合法source_ids；不请求/记录思维链。不足返回INSUFFICIENT_BUDGET而非截句。UNTRUSTED标记和原说话者/时间归属保留。

机械验证包括schema、来源存在/归属/范围、受保护原文仍在最终视图、实体/数字/单位/动作引用、预算与已覆盖范围。它不能证明任意语义保真；生产缺乏可验证资格的来源仍KEEP_EXACT，质量实验独立检查否定、例外、AND/OR、纠正、冲突和动作状态。

不通过验证的产物不得替代原文；失败原因与发生费用保留。相同源范围/内容/策略/模型只复用已有有效结果，不循环摘要，不从旧摘要凭空推导原文。

### 3.3 触发与运行时

- 小于70%不自动语义整理。
- 达70%且有合格已完成前缀可异步生成；不改变正在派发的已冻结请求，无来源则记录NO_ELIGIBLE_SOURCE。
- 达85%在下一任务模型派发前必须有有效安全视图，或明确不足；不边发边等后台补救。
- 目标55%，压后planned低于85%且保真/硬限通过可PARTIAL_REDUCTION；仍达85%不得派发。不能为到55%删除保护事实，也不能自动扩64K到128K。
- 每个派发边界最多一个job；如确需分批，全部子调用受同job预算限制，保留无重叠来源索引。

### 3.4 持久化与故障注入验收

隔离DB和受控provider注入以下窗口：claim后派发前；已发未存响应；响应已存未校验/发布；发布后未推进Run；checkpoint恢复；两个worker并发；过时源/CAS失败；入队失败；权限撤销；辅助费用预留失败/重复投递；worker丢失执行权。

证明恢复不会重选Memory、不越权发布、不把UNKNOWN_OUTCOME改为普通失败或可重试、不漏账/重复计同一已确认调用。mock只能支持其覆盖的保证；跨进程持久化主张要有真实数据库测试。

### 3.5 数据与实验：不重复通用RAG，也不编造业务语料

先检查已有公开数据与曝光台账。首选新增审核候选为 [QMSum官方仓库](https://github.com/Yale-LILY/QMSum)：官方说明为人工标注会议查询摘要数据，并提供会议文本、问题、参考答案及部分相关文本范围。它适合测试Thread内长历史压缩后的任务继续，不用于证明共享个人画像记忆。来源、许可及上游会议来源须执行时再逐项留档，不能把仓库license自动等同所有来源无限使用权。

只从官方train做小规模开发实验，按meeting隔离；先固定来源commit/文件hash、选样规则、question IDs和长度分布，禁止看B/C输出选题。保留自然发言顺序与speaker；作为提供给Agent的历史资料块，不能冒充真实用户和助手执行记录，会议中的建议也不能转成工具已执行状态。

冻结最多12题、每会议至多2题；选择规则只用来源/长度/任务资格，不看gold内容决定在线压缩范围。相关范围和reference只能用于离线评分，不能泄漏给压缩器或在线选择。不存在足够自然长样本时如实缩小分母；不填充/复制文字制造压力，不临时降低业务预算冒充64K业务收益。

保留QASPER已有公开材料作来源回溯回归的备选；若复用已曝光样本只报开发回归，不重跑原通用检索基准或称独立确认。所有人工构造的金额/否定/未知动作案例单列故障回归，不计公开主质量分母。

当前路由声明32768，不改称1M。首轮验证64K预设被模型下限约束后的真实B_work；若无达到触发压力的来源，完成无压力检查并报告“未验证高压压缩”，不可捏造大窗口实测。

### 3.6 对照、评分及有界调用

A只作旧实现历史参照，不必新增A调用；B为M3同模型同预算确定性策略；C为同B加唯一压缩候选。冻结B整交换选择/不足规则，禁止发送超窗B。每题最多一次摘要、B答案、C答案；按固定种子平衡B/C先后次序。若摘要并无可替代来源，记录不适用，不制造调用。

逐题评价：关键受保护事实完整、来源合法、角色/时间/状态正确、reference语义覆盖和无支持断言、原有词面指标（若可用）、输入/输出token、额外延迟、费用和不足/失败。词面分数不作唯一判据。主代理基于公开原文和参考答案审阅结果；无人类盲审时明确是代理审阅，不称人工独立评测。

预登记推广门槛：关键语义/权限/动作回归0；C相对B不得新增不支持的关键断言；逐题任务合格率不下降；实际有压力且B可答的配对中，后续任务输入token中位数下降至少20%；同时完整流程token/保守费用不高于B。未满足最后的净收益条件可完成机制验收但不推广。小样本只给描述性结果，不据此宣布统计显著、通用最优或默认上线。没有可计费价格、有效压力配对或可靠评分则相应结论标UNVERIFIED。

为避免反复停下来询问小实验，执行代理在既有API测试授权内采用以下**工程保守上限**（不是声称用户指定了金额）：M4+M5合计最多80次供应商dispatch尝试、150万估算输入token、6万请求输出上限token；能确认真实适用单价时另设累计保守费用5元人民币上限，全部以先到者停止新增调用。计数包含摘要、答案、校准、缓存写入/读取、fallback与失败尝试；并发预留最坏费用，未知调用保留预留，不预算透支。

M4最多40次，M5最多16次，其余仅用于已登记的校准/明确本地修复后尚未派发题，不能用来换候选扫参数。首个未经确认的远端派发结果立即停止该实验的新请求并进行账本核对，不自动重试。确定性本地错误在证明确实未发请求后可修复继续。

派发前核实价格/计费来源：已有本地Magpie账户若按订阅/额度计费，只在其已配置允许范围运行并报告货币未知及token/次数上限，不能宣称5元硬封顶；按量付费备用必须先确认适用价格并预留，否则禁用该实验fallback，继续能运行的本地路线。不得新订阅、充值或新增外部服务。达到工程上限记录有界未完成，不自动加额度；继续零调用的开发、测试和M5独立工作。

## 4. M5：稳定表示、缓存复用与适用能力发现

### 4.1 先做通用确定性契约

在现有请求构造中固定发布提示和工具/schema的规范表示与顺序，动态当前输入/检索材料在合法边界后追加；不得为了前缀改变system角色、信任、工具时序、来源权限或最终内容。时间戳/计数/采集时间等审计字段不加入稳定提示。每次先通过硬预算，再考虑缓存。

摘要产物复用身份覆盖Workspace/Thread、source范围/hash、权限可见性、策略/prompt/模型/计数器版本和预算语义；复用的是已验证摘要，不缓存最终业务答案或工具副作用。失效/权限变化不再选入新请求，历史Run引用仍按原授权恢复契约处理，不能强行删除其历史证据。

### 4.2 供应商适配

核实已配置路由的官方文档与实际响应字段，区分UNKNOWN、UNSUPPORTED、SUPPORTED、ENABLED；`/models`只在明确支持字段时解析，不从模型名称或OpenAI兼容标签推断窗口/缓存。

先实现最小provider adapter接口和已确认的当前路由支持；若当前路由不提供原生显式缓存，交付不支持/隐式观测适配及fixture契约，不伪造缓存命中或另接服务。在线只读能力元数据可走现有配置端点、超时/响应大小上限与SSRF验证，重定向逐跳校验，不放宽私有地址或现有allowlist。

显式缓存仅在已有凭据服务及授权测试范围内、实际支持且费用预留后启用测试；租户/模型/工具/权限/prompt改变必须影响复用身份。区分本地摘要命中与供应商prompt cache读写token，两者不能混作一个命中率。

### 4.3 缓存验证与净收益

离线验证稳定前缀字节/规范语义、动态尾部变化、工具顺序与语义、租户隔离、权限变更、失效、计数和原文恢复。缓存读token仍占模型上下文，不能从N或B_work扣掉。

最多16次在线调用，采用不含私有数据的固定公开输入，冻结冷/热/不同前缀对照与先后次序；记录实际输出正确性、输入/输出/缓存读写usage、TTFT、端到端延迟、计费来源及预热费用。隐式缓存不可强制清空时标“首次观测”，不能冒充冷缓存；字段缺失标UNKNOWN。
