# AgentHub 前端：指标卡语义色（2026-10-28）

- 问题：仪表板里"失败数""需要处理"等异常指标被强调时统一用品牌蓝描边，语义不对（蓝≠告警）。
- 改法：`MetricCard` 增加 `emphasisTone`（accent / danger / attention / warning）；
  - 失败数 → `danger`（红）
  - 待审批 → `attention`
  - 取消请求 / 结果未知 → `warning`
  - 需要处理 → `attention`（琥珀）
- `primitives.css` 增加对应 `metric-card-emphasis-*` 边框色。
- 验证：`tsc` + `next build` 通过；深色/浅色实拍确认"失败数"红边、"需要处理"琥珀边，语义清晰。
