## 实现

### 冻结快照分片预览

- 新增 `GET /api/v1/workspaces/{workspace_id}/knowledge-bases/{knowledge_base_id}/snapshots/{snapshot_id}/chunks`。
- 复用 `KnowledgeSnapshotService.resolve_snapshot` 的内容权限、租户归属及成员哈希检查，权限为 `knowledge_run`。先验证权限和冻结快照，再查询分片。
- 按冻结 membership 中的文档修订关联分片；不调用 LATEST、不创建快照，也不按当前修订状态排除历史正文。
- 默认每页 10 条、最多 20 条；稳定按修订 ID、ordinal、分片 ID 排序。正文每条最多 4096 字符并返回截断标识。
- 知识库快照行和智能体 PINNED 绑定行共用一个组件。LATEST 尚未有冻结快照 ID 时继续沿用知识库入口，不冒充已冻结历史内容。
- 会话/工作区/知识库/快照改变会重置组件；页码与返回 offset 必须匹配才显示正文。权限未知或不足时禁用入口，错误与空数据分别显示。
- 前端校验返回 workspace、知识库、快照、页码、数量和正文上限；新增全部文案均有中英文键。

### 代码块复制

- 在现有无依赖 Markdown 组件内复用 clipboard 和 i18n；复制完整代码文本，保留换行、制表符，不复制围栏。
- 提供提交中、成功、失败状态；内容变化或卸载后旧 Promise 不再更新组件。
- 继续使用 React 文本转义，不插入 HTML。用 `contain: inline-size` 限制代码长行的内在宽度，代码自身横向滚动。

### 浏览器发现并修复的旧问题

1. 知识库详情页将轮询 `useEffect` 放在未登录 early return 后，登录初始化后产生 Hook 数量变化并崩溃。已将 Hook 移至分支之前，未连接时不启用轮询。
2. 会话中长代码使网格气泡撑宽到约 3457 px，正文被外层裁切。修复后 375 px 屏宽下气泡约 301 px、代码可视区域约 275 px，长行在代码块内滚动。
