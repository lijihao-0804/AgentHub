# 工作区外观、历史数据走查与阿里云问答复测

## 外观设置

从账户菜单进入「外观」，或打开「工作区设置 → 外观」。用户可选择浅色、深色、跟随系统，搭配钴蓝、青绿、鸢尾紫、铜橙、石墨灰五个预设，也可直接输入六位十六进制色值或使用浏览器取色器。浏览器会保存选择并同步到同源标签页。用户输入的颜色用于生成按钮、链接、选中态和焦点色，成功、告警和错误继续使用各自的语义色。颜色角色的划分参考了 [Radix 自定义配色](https://www.radix-ui.com/colors/docs/overview/custom-palettes) 和 [GitHub Primer 颜色用法](https://primer.style/product/getting-started/foundations/color-usage/)。

真实 Edge 会话从登录页进入历史工作区，经账户菜单打开设置，验证了预设、合法与非法输入、系统明暗变化、刷新、跨标签同步和恢复默认。320、390、768、1366 像素宽度分别覆盖明暗两种模式、5 个极端自定义色，共 40 组，正式构建上主按钮最低文本对比度 6.33∶1。逐组检查均无横向溢出和页面脚本异常。另对 80 组颜色、明暗两种模式和 12 类界面角色测量 1,920 项，在侧栏小字首次未达标后修正了派生颜色。[桌面外观设置](evidence/workspace-quality-20261118/appearance-desktop.png) · [手机深色设置](evidence/workspace-quality-20261118/appearance-mobile.png)

## 历史工作区

本地已有专用 QA 成员，原组织角色为成员，目标工作区角色为只读。原开发库停在迁移 0055，直接运行本分支时知识库及审批查询出现 HTTP 500。在原库的一致性副本升级到 0060 后，使用同一成员登录。两库均有 406 个工作区，目标工作区的八类资源 ID 集合逐项一致。工作区包含 78 条运行、49 个会话、5 个智能体、17 项工具、3 个知识库、3 项审批、3 个评测数据集、1 个实验和 1 份价格快照。升级原有部署时需先执行 `alembic upgrade head`。

三个操作问题经实际点击复现并修复。搜索尚未加载的历史运行时，空结果现在仍提供下一页入口，验证时找到了第二页的目标运行。点击「需要处理」会同时更新地址、筛选控件和列表，只列出历史数据中的 2 条记录；令牌自动续期会保留已经翻开的页。选择下拉项后菜单会关闭，将焦点还给触发控件，可以紧接着打开首条运行。

用 1440×960 桌面视口与 390×844 移动视口走查，核对了运行、知识库和审批列表，进入运行、工具、知识库、会话、评测数据集和实验详情。最终两次走查均无失败业务 API 请求或页面脚本异常，手机页面无横向溢出。原工作区的截图仅保存在本地，公开截图仅含外观设置控件。
