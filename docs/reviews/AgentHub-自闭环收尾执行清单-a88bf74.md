- 性质：**执行清单**。用户指示（2026-10-25）："有用的小活直接安排，把可以收尾的都收尾，不要再让我决策或输入。"本单所有任务的数据、判据、预算均已定死；执行者按序自走，唯一例外见"唯一升级点"。
- 基线：`a88bf74`（分支 `codex/rag-aliyun-regression-20261024`）。纪律沿用总执行计划 §0/§1；**抽样纪律**：模型调用默认 100 题≈200 次调用，可降至 50 题≈100 次；本单各任务调用预算单独写明，超限即停。
- 任务顺序按"独立性"排列，可并行处已标注。

## T1【B1 表格解析试点：金标语料改用 TAT-DQA，人工标注项取消】

原 B1 卡在"20-30 个 PDF 的人工金标"。**替代数据源已调研定案**：[TAT-DQA](https://github.com/NExTplusplus/TAT-DQA)（Amazon 资助 NExT+ 计划发布）——**2,758 份真实财务报告 PDF、3,067 页、16,558 个带答案的问题**，含表格与文字混合排版；官方 GitHub 提供下载；许可为**非商用研究用途**（论文 [arXiv:2207.11871](https://arxiv.org/html/2207.11871v3)），仅用于 benchmark 试点符合用途；备用数据集 [WikiTableQuestions](https://huggingface.co/datasets/stanfordnlp/wikitablequestions)（半结构化表，非 PDF，兜底用）。

- T1-1 协议预注册 `results/table-parse-<日期>/protocol.json`：抽样 **30 份文档 / 100 题**（固定 seed，只取答案可唯一定位到单一表格单元格的题——过滤规则写死：答案字符串与某单元格值精确匹配）；指标=单元格事实送达率（答案所在表格区域是否进入 top-5 证据）；门槛：**当前 pypdf 基线送达率作为基线值记录，试点解析器须 ≥ 基线 +15pp 且 CI 下界 >0**；0 次模型调用（纯检索/送达测量）。
- T1-2 下载与预处理（本地，0 调用）：下载 TAT-DQA 抽样子集，按过滤规则生成 100 题考卷与 gold 表格区域标注（用数据集自带坐标/页码字段，**不做人工标注**）。
- T1-3 基线测量（0 调用）：当前生产解析器（pypdf 逐页）过 30 份 PDF → 切块 → BGE-M3 → Qdrant 隔离集合 → 混合检索 top-5，记录送达率作为基线。
- T1-4 试点选型（0 调用）：两条路线各 5 份文档对比：(a) `pdfplumber` 型纯 Python 表格抽取（轻量，优先试）；(b) RAGFlow DeepDoc 子模块（重，含视觉模型——仅在 (a) 基线送达率 <40% 时才试）。评估维度：表格单元格文本完整率、阅读顺序、每页处理耗时。
- T1-5 端到端对比（0 调用）：胜出解析器按 B1-4 契约接入临时解析路径（`ParsedBlock` 增 `table` locator 类型、整表成块、表头行携带），过完整管道测 100 题送达率。
- T1-6 收口：达门槛 → 表格解析生产接入提案（媒体类型白名单、Celery 解析子进程、资源上限），交用户批准后另批实施；未达 → 负结果收口（附"TAT-DQA 财报表格形态 vs 目标语料"适配性说明）。**全程 0 模型调用；若两条路线都 <基线+15pp，如实写负结果（这也证明目标语料若非财报型则 B1 优先级本就不高）。**

## T2【F 桶合并版收口实验：拒答守护 + 压词约束合并设计】

上一单遗留的"重开方向"已具备免决策启动条件（机制有效 78.2% 已证、失败原因已定位为对冲），补一个合并设计即完整：

- T2-1 协议预注册 `protocol-f2.json`：**合并干预** = 压词结构化输出（上轮已实现可复用）+ **拒答机械护栏**："参考证据集合中存在与问题高度重合的记录时（判定：query 与记录的词面重叠 ≥ 阈值，预注册固定值），模型不得输出 unanswerable；护栏在提示层注入检索分数/覆盖信号，不改模型自由度"。100 题（seed 同族）、before=当前默认（复用冻结 gold 答案，0 调用）、after≈**100 调用**。
- T2-2 门槛（预注册）：F 桶回收 ≥50% 且整体 F1 ≥ +4pp 且 CI 下界 >0 且 **拒答率不升（≤20%）**——上轮三缺门逐一对上。R 桶题数不得增加。
- T2-3 收口：PASS → 生产提案（限事实型短答案）+ 四件套 + 报告；FAIL → F 桶**终局关闭**（两种设计都测过，不再重开），报告写明"生成侧词面优化到此为止，剩余为模型能力与评分口径"。
