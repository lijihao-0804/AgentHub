# AgentHub 前端 UI 重设计（2026-10-28）

## 背景

10-27 的《前端体验问题清单》已完成多轮"降噪 / 删文字 / 压缩时间线"，但整体仍是
一款通用的深灰后台：淡绿强调色 + 全大写分组标签 + 单色按钮，缺少产品辨识度。
本轮做一次有明确美术方向的设计系统升级（不改信息架构与业务逻辑）。

## 设计方向：Instrument Console（仪表控制台）

- **气质**：工程精密、低噪、安静而自信。服务于"运行 / 审批 / 评测 AI 智能体"的操作台。
- **配色**：冷石墨底，表面逐层抬起；**单一"信号青"强调色** `#56d4c6` 只用于交互态
  （激活导航、链接、聚焦、主按钮）。状态色冷暖分离：成功绿 / 警告琥珀 / 危险珊瑚 /
  信息蓝，running（青）不再与 warning（琥珀）混淆。
- **主操作**：按钮改为信号青填充 + 轻投影，成为页面上唯一被"记住"的元素。
- **形态**：圆角收紧为 6 / 10 / 14；阴影分层更克制；字号体系加大一档、行高 1.6；
  头像/品牌用一个"信号宝石"图形代替图片资源。
- **克制**：唯一的装饰是一道从透明到强调色再透明的顶部发丝线（首页 hero 与登录卡）。

## 令牌（暗色）

| 用途 | 值 |
| --- | --- |
| background / surface / raised / nav | `#0e1116` / `#141a21` / `#1a222b` / `#11161d` |
| border / border-strong | `rgba(255,255,255,.07)` / `.15` |
| text / muted | `#e6eaf0` / `#98a2b0` |
| accent / accent-ink | `#56d4c6` / `#06201d` |
| radius sm/…/lg | `6 / 10 / 14` |

浅色主题同步给出（accent 加深为 `#0f766e` 以保 AA）。所有颜色仍集中在
`apps/web/app/styles/tokens.css`，其它样式文件零写死颜色，因此换肤是安全的。

## 本轮改动文件

- `tokens.css`：新调色板 / 圆角 / 阴影 / 字号（新增 `--text-xl/2xl`、`--radius-pill`）
- `base.css`：字体渲染、字号层级、`::selection`、body 顶部微光、`eyebrow` 去大写
- `shell.css`：品牌宝石标、侧栏分组字重/去大写、导航选中态、内容框 1200px + 入场动画
- `primitives.css`：按钮（填充/悬停/按下）、面板投影
- `pages.css`：首页 hero 信号发丝线、应用卡/快捷卡悬停层次
- `auth.css`：登录/注册卡片（发光背景 + 顶部发丝线 + 输入聚焦环）
