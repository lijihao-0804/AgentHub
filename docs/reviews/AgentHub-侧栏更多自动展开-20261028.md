# AgentHub 前端：侧栏"更多"自动展开（2026-10-28）

- 问题：侧栏把智能体/知识库/工具/评估/设置折叠在「更多」里；当直接进入这些路由（如 `/agents`）时，
  「更多」仍收起，用户看不到当前所在位置（无高亮项）。
- 改法：`SidebarContent` 读取当前路由，若命中 `MORE_ITEMS` 则自动展开「更多」；折叠状态下若其中
  有当前页，则给「更多」以强调色。
- 验证：进入 `/agents`，「更多」自动展开，"智能体"高亮为当前项。
