# AgentHub 前端：首页对话入口 + 深层巡检（2026-10-28）

## 首页"对话优先"入口

- 首页顶部新增 `.home-composer`：「描述你想让智能体做的事…」输入框 + 应用下拉 + 「开始」主按钮。
- 提交后跳到对应应用并带上 `?draft=<任务文本>`；`AppWorkbench` 读取 `draft` 预填会话标题，
  并在未固定智能体时**自动选中第一个可用智能体**，因此「创建会话」按钮立即可用。
- 实测：输入任务 → 开始 → 落到 `/research?draft=…`，智能体=Research Assistant、标题=任务文本、按钮可用。

## 深层巡检（真实数据，15 个二级/深层路由）

逐一打开并采样运行时错误 / 白屏：

- 全部 **无前端崩溃**（无 PAGEERROR、无 "Application error"）。
- 数据集/实验/评估运行/定价/门禁/智能体详情/调试台/工具详情/MCP/知识库详情/检索台/成员/运行对比均正常。
- 仅少数 404 / 405 来自 Docker 内的旧后端镜像（接口缺失或方法不符），属环境问题，
  页面以错误卡片正常呈现，不是前端缺陷。
