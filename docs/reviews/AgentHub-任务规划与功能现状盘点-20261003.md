- 记忆运营：衰减策略、自动 TTL 分配/清理、条数上限参数化及真实 trace 上的写入门调优；字段存在不代表完整运营策略存在。

- OTel GenAI 标准化接入，以及持续运行于 CI 的浏览器 E2E。现有前端行为脚本与浏览器验收已经存在，所以“前端 0 测试”过时；CI 前端 job 当前仍主要是安装与构建，不能说已有完整 E2E gate。
- 反馈运营聚合：有反馈记录及工作流，但 O01 运营聚合页面、真实用户采纳率未补齐。
- M8 公网交付：未找到完整公网部署验收、完整 web/nginx 部署链和 3–5 分钟演示视频证据；登录/上传/run/model-test 等完整 rate-limit 能力未在当前实现中找到。既有 SSRF、凭据加密与 CI 可复用，不能说安全完全没做。

## 4. 验证缺口，不应混记为功能缺失

- 真实对照与 RAG 评测已有，但使用合成客服政策数据、隔离环境和助手复核；独立真人 judge agreement/Kappa 仍未知。
- Q09 记忆保持/误用系统性消融仍在候选清单。历史 memory-on/off 小规模真机验证已有，不能据此宣称覆盖最新计划要求的使用/禁止使用分类数据集。
- 实际进程故障三窗口：安全终态 3/3，业务自动恢复 1/3；其余 claim 丢失需人工对账。应保留这项产品限制，不能包装成全窗口自动恢复。
- 受控 provider 的 636 次负载、真实 provider 首字样本、worker 故障及租户/注入测试已有；不等于饱和容量、完整容器 RSS/资源监控、生产 SLA 或普遍安全性。
- A1–A4、M5-B、M7-G 的指定独立验收文档缺失，以及施工分支尚未合入 main，属于证据/交付收口。
