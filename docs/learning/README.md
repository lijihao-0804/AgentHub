## 怎么用这套教材

### 快速准备面试

先学 00–05 的执行骨架，再读 07/08 的质量与实验边界，最后做第 10 课的口头验收。时间不够也必须能指向真实函数；不把快速读完等同于掌握。

### Agent 岗位重点路线

按 00→02→04→05 建立执行与治理主线，再读 06/07/08 的知识、记忆和质量边界，最后精读 [11 · Agent 工程强化](11-agent-engineering.md)。01/03 帮你补请求入口和版本身份，09 补业务闭环，10 用隔离练习检验理解。重点能讲清工具提议为何不是执行成功、两个调用身份为何分开、观察如何驱动下一轮，以及未知写入为什么不能重试。

### 完整掌握

顺读 00–09，每课做纸上/只读练习；第 10 课先 L0，再做隔离的主 Demo/恢复/失败实验，然后补 RAG、Memory、Evaluation 和反馈接管。记录实际结果，失败也保留。第 11 课再从 Agent 工程角度串起主线和面试追问。

### 每课只留下六行自己的笔记

```text
我要解决的问题：
核心数据与调用链：
我找到的真实函数：

能否不看材料解释给面试官：
```

不能回答某课的通过标准，就回对应函数，不继续扩大阅读量。记录是你的学习成果；教材、已有测试或别人生成的回答不替你完成学习。

## 实验与证据必须分开

- 正文中的“预期”是未来练习目标；没有执行就写未执行，不预填 PASS。
- 源码/注释版标出出处，流程图只表达指定主线，省略分支明确说明。
- 已冻结历史验证只按其 SHA/日期/模型/数据解释，本轮文档检查不等于再跑这些实验。
- 默认先做只读源码/JSON，无服务和模型费。需要服务时只用第 10 课的隔离 lab 环境。
- 不改运行时、已发布版本、测试断言或正式结果凑展示；不覆盖共享 `.env`，不重试未知写入。

## 本次详细版怎么读

每课保留前半部分的主线说明，后半部分“精读增补”用于真正学会。建议同一课连读两次：第一次串起输入、输出、身份和状态；第二次打开链接的真实函数，把正文逐条与代码核对，再独立回答练习。所有练习、自测、追问均配参考答案：纸上题给出结论、解读与核查位置，实验题给出条件性预期、观察证据和失败排查。参考答案不替代你的实际运行记录。

00 建立架构和教学身份；01 补 Python async/数据库阅读基础与提交竞态；02 展开 prepare 三重校验和消息账本；03 展开 canonical hash 与冻结链；04 用真实 claim 函数讲并发；05 按 crash 窗口和事件游标推理；06 手算 RRF/MRR；07 拆解 savepoint 与 WRITE/RECALL/ADMISSION/USE；08 手算任务、分母与费用；09 展开反馈幂等与接管版本冲突；10 提供只读观察 SQL、口头参考解答和综合排障题。

- 第 10 课的 12 道口头题有参考展开、源码/字段和失败边界；综合题及五种变式均有解答。
- 第 11 课新增 Q11-01 至 Q11-10，十道 Agent 追问均附答案与解读，综合推演也给出参考答案。
- L0–L10 每个实验都给出条件性答案与确认方法。课堂不能替你预测某次模型的精确措辞，实际结果应据 Run/Approval/事件和原始输出判断。
- MQ04/MQ07/MQ09 的四列答案直接来自已提交 JSON，null、UNKNOWN、脚本 USE 和真实模型 USE 分开解释。

## 源码导读与注释规则（2026-10-26 更新）

每课开头的“源码导读”用三列表格解释入口职责、输入与产出、阅读重点。正文里遇到“先读/打开”，可先对照本课导读，不再只有一个函数名让你自行猜用途。ORM 映射、装配函数、条件路由和实际执行函数分开说明。

Python 源码代码块加入中文 `# 学习：` 注释；逐字源码保留原执行语句，教学流程明确标为示意。第 11 课 observation 已改为 text 流程，避免过时节选被当成当前完整函数。代码块可能省略导入、装饰器、类或调用上下文，并非可直接复制运行的完整脚本。框架注册、长参数表、SQLAlchemy 条件更新和远端结果分类均按关键步骤解释。核查时去掉学习注释即可与原节选对照。

先看函数作用和输入/产出，再顺着注释读关键步骤，最后检查本课的题目与答案。不要把注释描述的意图当成已执行测试；恢复/外部副作用等保证仍按对应证据边界理解。


### 排版与使用

正文主线按二级标题阅读；源码导读集中为三列表格；Python 源码用普通 Markdown 代码块直接展示，并用“带注释源码”标出用途。精读部分的 A–F 是三级标题，具体 Q 编号题是其下的四级标题；答案、解读和核查依据均直接可见。

课程使用标准 Markdown 表格与代码块，不依赖 HTML 换行或折叠标签。教学注释作了分行，原执行语句仍按源码保留；长执行语句横向阅读，不为了排版改写语义。
