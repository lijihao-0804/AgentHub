# AgentHub 全链条学习路线

**只从 [00 · 架构](00-architecture-first.md)开始，按 00→10 顺着读。** 本目录现在是完整教材，第一次不用在报告、题库和源码之间自行拼路线。2026-10-09 整合；源码基线 `823ac05`。

贯穿案例是 Incident 的调查→工具提议→审批→恢复；RAG/Memory/Evaluation 再接回同一个 Runtime。每课先讲问题和机制，再给真实函数/代码/流程；精读增补继续拆解数据变化、并发与失败推演，并配练习和参考答案。学会之后再练面试，而不是先背简历句子。

## 怎么用这套教材

### 快速准备面试

先学 00–05 的执行骨架，再读 07/08 的质量与实验边界，最后做第 10 课的口头验收。时间不够也必须能指向真实函数；不把快速读完等同于掌握。

### 完整掌握

顺读 00–09，每课做纸上/只读练习；第 10 课先 L0，再做隔离的主 Demo/恢复/失败实验，然后补 RAG、Memory、Evaluation 和反馈接管。记录实际结果，失败也保留。

### 每课只留下六行自己的笔记

```text
我要解决的问题：
核心数据与调用链：
我找到的真实函数：
机制为什么这样设计：
一个失败/未知边界：
能否不看材料解释给面试官：
```

不能回答某课的通过标准，就回对应函数，不继续扩大阅读量。记录是你的学习成果；教材、已有测试或别人生成的回答不替你完成学习。

## 实验与证据必须分开

- 正文中的“预期”是未来练习目标；没有执行就写未执行，不预填 PASS。
- 原样源码标出出处，流程图只表达指定主线，省略分支明确说明。
- 已冻结历史验证只按其 SHA/日期/模型/数据解释，本轮文档检查不等于再跑这些实验。
- 默认先做只读源码/JSON，无服务和模型费。需要服务时只用第 10 课的隔离 lab 环境。
- 不改运行时、已发布版本、测试断言或正式结果凑展示；不覆盖共享 `.env`，不重试未知写入。

## 本次详细版怎么读

每课保留前半部分的主线说明，后半部分“精读增补”用于真正学会。建议同一课连读两次：第一次串起输入、输出、身份和状态；第二次打开链接的真实函数，把正文逐条与代码核对，再独立回答练习。所有练习、自测、追问均配参考答案：纸上题给出结论、解读与核查位置，实验题给出条件性预期、观察证据和失败排查。参考答案不替代你的实际运行记录。

00 建立架构和教学身份；01 补 Python async/数据库阅读基础与提交竞态；02 展开 prepare 三重校验和消息账本；03 展开 canonical hash 与冻结链；04 用真实 claim 函数讲并发；05 按 crash 窗口和事件游标推理；06 手算 RRF/MRR；07 拆解 savepoint 与 WRITE/RECALL/ADMISSION/USE；08 手算任务、分母与费用；09 展开反馈幂等与接管版本冲突；10 提供只读观察 SQL、口头参考解答和综合排障题。

## 答案阅读规则（2026-10-10）

- 每课原始练习的答案紧跟题目，不再只写“提示方向”。
- 精读增补的 30 道题按章编号 Q00-01 至 Q09-03，00–09 每课三题，逐题列“答案、解读、核查依据、常见误解”。
- 第 10 课的 12 道口头题有参考展开、源码/字段和失败边界；综合题及五种变式均有解答。
- L0–L9 每个实验都给出条件性答案与确认方法。课堂不能替你预测某次模型的精确措辞，实际结果应据 Run/Approval/事件和原始输出判断。
- MQ04/MQ07/MQ09 的四列答案直接来自已提交 JSON，null、UNKNOWN、脚本 USE 和真实模型 USE 分开解释。

问题只问机制时，答案应能明确给出；问题依赖现场条件时，答案应说明条件与各分支。未知不会被写成保证成功，个人贡献和个人实验事实也不能由教材代填。
