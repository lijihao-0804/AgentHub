# M1 — Auth / Tenant / RBAC

## 当前状态

M1-A 至 M1-D 的代码实现和 M1-E 的 PostgreSQL 集成测试已提交到
`m1/auth-tenant-rbac`。由于当前环境没有真实 PostgreSQL，M1 acceptance 暂不能标记为
`PASS`。

## 已实现范围

- Argon2id 密码哈希、短期身份 JWT、opaque refresh token rotation/reuse detection；
- `users`、`auth_sessions`、Organization/Workspace membership 与 `audit_logs`；
- `PrincipalContext → OrganizationContext → WorkspaceExecutionContext`；
- OWNER/ADMIN、DEVELOPER、VIEWER 的服务端权限解析；
- workspace 成员 API、跨租户 404、最后一个 Owner 的并发锁定保护；
- 真实 PostgreSQL 集成测试入口，禁止用 SQLite 替代。
