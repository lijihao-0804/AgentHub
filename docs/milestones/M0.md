# M0 — Engineering Baseline + Semantics Freeze

## Scope

M0 establishes the repository, API factory/lifespan, configuration, request and trace IDs,
structured JSON logs, error envelope, health endpoints, migration boundary, checkpoint
bootstrap boundary and stable contracts for ModelGateway, KnowledgeRetriever and TraceSink.
Infrastructure configuration and deployment entrypoints are present, but runtime dependency
verification is intentionally deferred.

## Explicit non-goals

No authentication, tenant CRUD, Agent runtime, RAG pipeline, Tool runtime, Approval runtime
or evaluation product is implemented in M0.

## M0 blocking acceptance

```text
[ ] fresh clone and .env setup
[ ] uv sync and lockfile
[ ] pytest
[ ] ruff check
[ ] frontend npm build
[ ] GitHub Actions
[ ] Alembic / checkpoint bootstrap code, ADR and script static checks
```

Docker startup and real PostgresSaver bootstrap are not blocking M0 acceptance.

| Verification | Deferred to |

These are intentionally deferred infrastructure checks, not M0 failures.
