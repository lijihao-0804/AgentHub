# M0 — Engineering Baseline + Semantics Freeze

## Scope

M0 establishes the repository, API factory/lifespan, configuration, request and trace IDs,
structured JSON logs, error envelope, health endpoints, migration boundary, checkpoint
bootstrap boundary and stable contracts for ModelGateway, KnowledgeRetriever and TraceSink.

## Explicit non-goals

No authentication, tenant CRUD, Agent runtime, RAG pipeline, Tool runtime, Approval runtime
or evaluation product is implemented in M0.

## Acceptance checklist

```text
[ ] fresh clone and .env setup
[ ] docker compose starts PostgreSQL, Redis and Qdrant
[ ] alembic upgrade head
[ ] explicit checkpoint bootstrap
[ ] pytest
[ ] ruff check
[ ] frontend npm build
```

The checklist is completed only after the commands are run against the current commit.
